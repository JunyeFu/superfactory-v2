# 三类模板、交接与继续的有限预期

源模板是modules/templates里的三份独立设计工程。执行 `python 推导模板接手预期.py` 检查所用模块版本、公开参数、端口/库位类型、角色/阶段和初始材料，再生成[有限预期](expected-template-handoff.design.json)。这不是产品运行、真实接手或专业程序验证。

三类工程各2件，300秒窗，数据全为自建声明。机械模板包装接受90/150秒；外购总装70/110秒；并行制造160/200秒。并行制造只把板件准备30改90秒后为220/260秒。检验与板件后续处理/放行均预设或声明，不证明实际几何、焊接、电气质量或客户履约。

导入已有工程只加入布局/定义，初始库存/订单默认不复制；缺图片可明确换表现，缺行为阻止相关作业；请求专业结果但未提供者不退回工时；这些是接手决策的期望，不是编辑器功能已通过。

继续示例保持原时间参考T=60秒：原作业有效20/40秒，剩余20秒在80秒完成；在途物品75秒才接受；未来到料90秒保留，过去事件不重放。已接受需求基数2，新增2，累计4；新运行不再次生产基数2。专业状态不可恢复时只能阅读或从头新跑。当前没有真实快照。
