# 投用、公用服务与专业成果的贯通设计例

全部数值为自建演示输入，不是企业实绩。有限脚本仅复算逻辑与契约预期，没有专业求解器或生产运行引擎；producer_result和actual_result留空。

## 建设时间对应到同一生产窗口

共同工程建设D0 00:00，计划生产观察起点D4 08:00。机械安装计划0—3日；基线柜体0—2日，接线2—3日，联调3—3.5日，模拟投用D3 12:00；延期柜体0—5日，接线5—6日，联调6—6.5日，模拟投用D6 12:00。它们是计划日历跨度，不代表施工人员24小时连续作业或现场联调已通过。

生产每天08:00—16:00可用；需求2件，齐套在观察起点已经到位，初始无成品。装配每件30分钟，检查5、包装5，W-A装配、W-B共用检查/包装，检查预设PASS。工位间移交瞬时，接收容量2；没有隐含维修、运输、加班。

|方案|投用相对生产起点|原24小时窗|同起点扩至72小时|
|---|---|---|---|
|基线|早20小时|2件，70分钟完整完成|同样70分钟|
|柜体延期|晚52小时|0件，完成为空|52小时＋70分钟＝53小时10分完整完成|

延期不能把生产观察起点和交期跟着挪走。3.5日投用与完成图纸/安装是不同节点；案例的决定是明确预设，仅用于模拟。

## 电和气必须同时满足

两台设备各加工1件，各30秒、6kW、2L/s。设备已投用，两个操作者独立可用0—120秒。气量采用同一自由空气参考20℃/101.325kPa；服务品质按自建声明匹配，没有压降或电制求解。背景/待机用量0；原料各1、产出各1，缓存各2。

|供电kW/供气L/s|预期过程|完成|
|---|---|---|
|10/3|两机顺序，0—30、30—60|60秒|
|14/3|气仍限制并行|60秒|
|10/5|电仍限制并行|60秒|
|14/5|两机0—30并行|30秒|

声明负载累计能量都0.1kWh、用气都120L。更快并不自动节能；扩容设备成本未知，不能计算回报。只计算共享容量，不据此保证实际末端压力或电网安全。

另一个变体在40—70秒断供电：第一件30秒完成，第二件30—40做了10秒；该工序明确允许pause_resume，保留物品/机器、释放服务，70—90再做20秒，最终90秒。没有定义中断处置的工艺不允许自动采用这种恢复。

## 专业成果的版本与支持范围

接口样例：产品r1包络100×60×30mm，r2为108×60×30mm；旧盒净空间104×64×34，新盒112×64×34，每侧间隙2mm，不允许换姿态。r1旧盒满足、r2旧盒不满足、r2新盒满足。

这只是轴对齐包络算术，不是纸包装成型/取物/强度求解。r1成果继续用于r1订单；把r1旧绑定拿给r2则不接受。r2名义包络条件满足，也不代表完整折叠/制造范围已获认可。请求实际名义NC却没有计算结果、程序超出方言范围、气量参考条件不同都形成明确未支持/需复核结论。

纸包装完整专业任务仍沿用已有板片/折带/连接、成型/开合、硬条件、制造层和接手工程，不缩为这个接口例子。
