# 设备创作、实例采用与等待表现

自建设计变体，不是运行产品或工业参数。用途是核对作者编辑如何影响设备定义、实例、状态表现与交接；不另写产品引擎。

[输入](inputs.design.json) → `python 推导创作预期.py` → [有限预期](expected-authoring.design.json)。正式结果一直为空；完整软件验收由P3执行。

|变体|明确改变|需要说明的后果|
|---|---|---|
|60秒单阶段|基线|2壳体、1PCB、1人，只能形成1件；设备示例不变为工程库存|
|30秒单阶段|只改工时|片段按比例缩放；仍只有1件，下一件缺PCB|
|60秒重排画面|只改未绑定行为阶段的图片次序|画面比例重算；配比、工时与预期数量保持|
|多阶段等待与待移交|下料员55—70秒忙、输出75—85秒满|55—70秒保持自动段结束姿态；75—85秒保持完成姿态，尚未接收|
|外观升级|只有A实例采用新外观|B版本保持；旧结果仍指旧方案，不生成新运行成功|
|行为升级|只有A改60为30秒|A需重新彩排；B仍60秒，不能把旧产量绑定到新输入|
|端口ID变化|旧pcb改为pcb_v2|原连接/标签待重绑；仅文字重命名不影响稳定ID|
|交接与公开|示例资产分别允许或不允许再分发|受限文件不附公开包；保留明确替换位置，不能丢掉行为|

单阶段样例采用四个未绑定真实工艺阶段的表现片段，比例0.2/0.35/0.3/0.15。60秒为12/21/18/9秒，30秒为6/10.5/9/4.5秒；这里的四段不是四次物料加工。多阶段例独立声明上料10/自动45/下料5秒，生产阶段不可被拖图重排。

多阶段例持有设备与在制，人员仅上下料占用，hold_on_output_wait=true。接收事件85秒才令输出进入库位且释放设备。等待期不计有效加工；合计有效作业60秒，制造阶段75秒结束，设备占用85秒。未模拟其他工位、几何、真实中断或控制器。

版本和素材变体是拟议决定的声明结果；许可条件是自行设计的输入，不声称已有某设备素材许可。只有实际编辑器、保存重开、实例升级、运行与导出结果才证明产品能力。主规则见[设备创作与采用](../../docs/02_交互设计/自定义设备创作与采用.md)。
