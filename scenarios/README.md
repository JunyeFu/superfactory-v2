首个采购件人工装配场景；之后并行制造场景及跨厂场景。场景写清输入假设与预期现象。

[并行汇合与返工](并行汇合与返工/README.md)覆盖两支线齐套、检验分流、返工复检、失败隔离和未知结果待判，包含声明工程与三组预设检验输入；属于设计样例。

[两厂房装配包装](两厂房装配包装/README.md)提供完整工程声明、仅补一片PCB的A/B方案和关键事件手算。设备、库存位置、人员、供应与订单都有明确引用；尚未执行的结果保持空。原[人工装配样例](人工装配样例.json)继续作为单设备隔离样例。

[从零搭建控制盒厂房](从零搭建控制盒厂房/README.md)：空工程到采购、加工、齐套、返工、包装与交付；两种到料预期为有限手算，实际结果为空。

[真实业务设计](真实业务设计/README.md)：多订单换单/目的接受、阶段班次、待判/报废和渐进细化；六个预期变体为自建算术，无运行引擎结果。

[投用与专业接入](投用与专业接入/README.md)：建设/生产起点、公用容量并行/中断、专业绑定版本及范围；9个预期变体，没有运行结果。
