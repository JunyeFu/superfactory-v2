这里是S03-04独立设计输入，不是当前可运行工程或性能数据。三厂房/六条线/60设备/3000独立身份与路由、处理时间和两种分布都已明确；S07/S08映射到S06真实格式并冻结本地素材，S09才在实际产品执行。

只读机器记录未运行GPU/帧率测试；实际渲染GPU、WebView2与运行条件仍需取得。统计例验证p95/中位数/存取逐样本和软件负载算术，不宣称用户机器达标。

位置旧元组按`[宽,高,深]`记录，先按负载`coordinate_contract`映射到工厂`[X宽,Y深,Z高]`，渲染再旋转为`[x,z,-y]`。保留旧数值和独立产量预期，不把旧元组直接填入正式Pose；120个位置／逆变换及旋转朝向有有限数学核对，真实画面仍待实现。

48窗口／1800编辑／40存取仅是三项固定基准。完整11项验收还须完成规范JSON列明的38个必需检查组及各自分支；纸包装30秒体验另报，不能由基准速度替代离线、持久化、并发和专业正确性。
