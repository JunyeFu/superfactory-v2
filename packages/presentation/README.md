# packages/presentation

插图/动图/模型及详细/简化/区域三档呈现。P2/P3实现。

2026-10-13当前要求：设备与流水线的三维视口支持自由环绕旋转、平移与缩放；详细模型精细度对齐现有AI预览，模型须具备背面/底部。原俯视斜角是默认姿态，不能锁死相机。模型制作工具与运行引擎分开；[3D试样](../../tools/3d-proof/README.md)采用可导出GLB的命名网格及批处理/实例化，仅为表现证明，不改变P2/P3未完成状态。领域坐标X/Y/Z高转换为glTF/Three.js的X/Z负/Y高，即`(x,y,z) -> (x,z,-y)`，不能将原型Y向上的高度直接写入领域Y深度。

P3增加图片序列、原生box/cylinder/plane部件、姿态时间轴和标签投影。按工序进度选择片段与插值，按绑定字段显示读数；读取同一仿真快照，不改变库存或生产时钟。编辑器拖动播放头只改变外观回看；Agent读取实际渲染图来调整同一个设备草稿。
