# S01-04 完整工作链竞品与差异

复审日期：2026-10-13（北京时间）。本文件负责已有方案、贡献边界和开发取舍；产品职责以[S01-01](用户任务与产品边界.md)、[项目主线](项目主线.json)和[首版基线](首版交付基线.md)为准。官方资料核读见[本项阅读记录](../../../研究资料/阅读卡/S01-04_竞品原文核读.md)。本项完成桌面比较与开发规格，未运行本产品或竞品。

**结论：保留完整开放平台及C1渐进建模、C2变更与解释、C3共同创作与接手的组合贡献候选。**已有强方案覆盖完整仿真、对象复用、自动模型生成、Agent查询运行和包装工程交接；本项目需实现三段连接如何延续同一可编辑工程。相对优势、净人工时和新算法尚无实测，不能写成“行业首次”或“已领先”。这些未知不阻止按已确认范围开发。

## 组合贡献的实施责任

C1渐进创作/连续使用由W03九类/设备表现、W02画布与W05Agent共同落实；C2条件变更/专业与结果解释由W01生产、W04完整纸包装和W02追踪落实；C3共同创作/接手由W05工程/同源评估/桥及W00唯一状态落实。六窗口拆分只是实现组织，不是新创新主张，也不改变最强近邻覆盖结论。

比较仍按同输入/同质量完整任务，而不是本项目功能数量或开发速度。源代码独立实现不等于专利自由实施结论；许可/代码/模型/素材来源按实际引入记录，未取得竞品访问不声称实测领先。范围只取21任务、纸包装一个真实内核，其他40专业/7后置不因研究齐全进入实现。

[工量与成果框架](../04_开发与验收/任务框架与工量里程碑.md)中的预算不当净人工收益；实际同任务对照/采用验证仍按原T1—T3。这轮同步组合机制的生产者/消费者，不新增竞品试用或商业效果证明。

## 同一个用户任务

方案作者是有工艺输入的工程师/集成商，讨论者可使用来源明确的模板，接手者负责继续修改。任务不是展示一座动画工厂，而是：

1. 提供产品/BOM、工时、资源、班次、订单和到料条件；人工从空工程/模板开始，或向外部Agent给行业、日产接受目标和场地长宽高。
2. 查询原生或已导入社区模板和九类库，配置设备、物流及排期，得到可以继续编辑的厂内/厂际方案；缺数据明确待补，目标量不成为已生产量。
3. 按真实离散状态模拟，从订单缺口或等待定位物品、资源和当前阻断，初案达标时Agent直接保存交付，不强制修改；不足且允许修改时改一个条件后从同起点再运行/比较，否则说明不能修正。修正能力以独立不足案例检查。
4. 需要纸包装时修改受限结构，实际计算成型/开合/直线取物和制造输出；人认可指定用途后绑定包装工位，再观察生产影响。
5. 导出同一结果的PDF/HTML/CSV/JSON及单独的可编辑工程包；接手者重开、修改、运行，贡献者可将适用资产按九类复用。

该任务沿用UT-01至UT-07；功能验收仍按SF-01至SF-17分别执行，SF-15参赛材料不能由比较报告替代。首版保持三类通用离散模板＋纸箱制造生成配置、纸包装一个真实专业内核、21项任务；复杂交通/维修/服务、其他专业和无界最优搜索仍后置。纸箱制造与给成品装箱是两条不同任务。

## 比较口径

比较每个产品自己的完整工作方式；允许其原生库、正常配置、公开插件及熟练操作，登记实际版本、权限和使用的扩展。不要求竞品使用我们的九类JSON、两画布、MCP或文件扩展名；只核对能否完成同一业务工作及输出是否可继续使用。

共同输入必须包括相同需求、库存、工序配比/时间、人员、到料/日历、物流条件、观察窗和产品/包装版本。已有CAD、行为库和行业模板的准备工作计入准备负担；本项目模板和Agent也不能免费获得竞品没有的生产知识。先比较结果质量，再比较人工工作；简单办法或视觉工具可用于其适用子任务，不能冒充已经完成全链。

本表的“已覆盖”是官方公开能力/作者实验的证据，非本次操作验证；“未确认”不是“不支持”。功能版本、可编辑权限及资产可携带条件未核定的，不编造价格、学习难度或零成本交付。

## 同任务比较的执行规格

这是实现后的效果验证入口，不是本轮已执行实验，也不新增首版必须取得商业授权的门槛。先让本产品通过自身SF验收，再取得实际可用的竞品版本/权限；无法取得时将该对照标为未执行，不能据此认定本产品更好。

|任务包|共同输入/改变项|通过所需输出|
|---|---|---|
|T1 生产变化、表现与接手|复用[两厂房装配包装](../../scenarios/两厂房装配包装/README.md)的A/B完整输入：2套需求、240秒截止/窗口、60秒装配、10/30/10/30秒运输、15秒装盒，3人分别承担任务；B只增加第二片PCB。再仅换表现，最后交另一人修改一个供料条件|完整物品/资源事件与125/205秒手算预期核对；区分110秒货物接受和140秒人员返程。比较工程可修改性及输入/核对/修改/接手人工工作，不能只看终点或帧率|

T1的秒数仅是自建规则下的逻辑预期。T2不能把四分钟样例外推日产，T3不能把几何可取物当运输防护合格。产品需另按SF-12覆盖三机制/三类变化，T3不以单个对照算例缩减它。

每个方案留下最少可检查记录：实际工具版本/权限/插件及操作者经验，共同输入文件，额外模板/脚本/资产，准备与任务人工时间，求解等待时间，结果文件，修改与接手是否成功及原因。模板制作、学会工具、修错和复核计人工；机器等待单列。未运行、未完成或缺关键结果的任务不计算节省率，资料宣传值不填实测栏。不同产品内部对象ID可不同，但业务物品、数量、单位、起点及接受阶段必须对应。

先核对正确性和交付质量，达到同任务最低输出后才比较工作负担；报告步骤和原始时间，不设置任意总分。单次熟练操作只支撑该任务记录；要主张目标用户更易用，还需目标用户独立执行。与简单表格/工程师＋AI比较时保留其准备脚本和手算方法，不能人为限制使本产品获胜。

## 对外写法与开发决定

可以写“设计并拟实现九类可扩展工业模拟桌面平台，以C1—C3贯通目标/简化输入、条件化彩排和可编辑接手”；实际实现后按真实版本列已完成能力。现在不能写已降低工时、全面替代成熟仿真/CAD、全行业已适配、无需生产知识、无需许可接手全部资产、已形成社区生态。

继续开发已确认平台与纸包装闭环，不为了制造差异增加内核或削成单一动画工具。若同任务证明强近邻同样完成，具体撤回领先/独占主张，保留独立开放工程与适用用户价值；若本产品要求用户重建行为、结果不能追到输入或接手无法续改，修复对应已选任务后再报告完整链成立。

本项文档规格通过；completion_credit=1、evidence_credit=0.5保留。这里的0.5是原成熟度的“资料/逻辑支撑”档位；未取得同数据软件对照、目标用户净收益、专业正确性或第三人接手实测。本项不改变其他检查项的判断；已同步的S01-03文档通过保持，累计状态见复审入口。
