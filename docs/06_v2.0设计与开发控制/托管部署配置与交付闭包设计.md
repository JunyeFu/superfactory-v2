## 3. TLS及依赖选择

Native和设备使用固定HTTPS入口，保留证书验证；受管请求不跨主机转发凭据。数据库参考路径使用同区域PG的external完整DNS地址，并把允许来源限制到实际服务egress CIDR。Render内部TLS使用自签证书且不支持verify-full；本设计选择外部完整域名的证书验证路径。[数据库连接说明](https://render.com/docs/postgresql-creating-connecting)

数据库连接使用tokio-postgres的Require模式及postgres-native-tls生成的MakeTlsConnector，系统CA、域名验证和SNI保持开启，最低TLS1.2。Require负责要求加密，证书／域名由实际TLSConnector验证。连接失败明确返回失败，不使用明文或关闭校验的恢复路径。[PG适配器](https://docs.rs/postgres-native-tls/0.5.3/postgres_native_tls/)、[TLS配置语义](https://docs.rs/native-tls/latest/native_tls/struct.TlsConnectorBuilder.html)

|reqwest|0.13.5；关闭默认特性，json/query/rustls|Native网关出站|
|tokio-postgres|0.7.18；with-serde_json-1|云服务持久化|

OP01为GET /healthz，schema1、配置及实际连接SELECT1就绪时返回204空体，其余503空体；不返回项目、会话、boot或秘密。它只供平台路由准入，业务接口仍为C01—C20。[HTTP探测规则](https://render.com/docs/health-checks)

SIGTERM后停止接新请求，最多20秒等待原短事务／响应后退出；平台结束期保留30秒。中断造成未知结果时仍按原命令／receipt／snapshot身份核对；云新实例不建立新Host epoch，也不清空原占位。滚动期可短暂双实例，数据库原锁和唯一键继续生效。[平台部署生命周期](https://render.com/docs/deploys)
