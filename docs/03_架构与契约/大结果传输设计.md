# 大结果传输与消费者合同（AQ-01）

本合同补充18操作的公共Response，不增加业务操作、库存或结果存储服务。唯一字段源为packages/commands/api.design.rs；所有操作Schema/TS由原生成器派生。

## 选择与调用顺序

比较过两种方案：逐业务增加Run/专业/导入等分页或文件分支，调用方须认识各结果的切分方式；在共同传输层返回完整Response的受管引用，所有消费者共用一次解包。本版选择后者，已有Events/ObjectsAt分页仍供日常读取。仅请求需要的Summary/页，FullResult才读取完整运行；不为绕过大小限制重算或拼造业务结果。

CommandsService仍返回原来的R或ApiError。Host先在一致状态边界捕获响应与相应Run前缀，释放业务锁后序列化完整Response<R>。若整个IpcResponseFrame的UTF-8字节（含附件元数据）不超过1048576，回复原内联outcome；超过时，把原Response<R>写入Host私有不可变结果文件，外层outcome=managed，携带result_id/response_schema_ref/byte_length。外层request_id、api_version、context复制自原响应；response_schema_ref必须等于原操作目录的response_schema_ref，它是类型标识，不能作为客户端可选文件路径。文件中outcome只能ok/error，禁止递归managed。

## 字节、权限与生命周期

IpcResponseFrame.managed_results附唯一匹配result_id及handle_value；不得包含客户端路径、请求内句柄或伪TaskId。文件由Host实际结果表定位。Host对原连接/项目/Scope及原操作授权后，为每次响应重新以GENERIC_READ打开独立文件对象、偏移0，再DuplicateHandle到OS核验的桥进程，bInheritHandle=false。不能共享另一读取的文件偏移；句柄不是持久化权限。

Bridge核对已认证帧、原操作、request_id/context和唯一结果引用，读取恰好byte_length并检查EOF，按对应原Response<R> Schema解析，核对内部头与外部头相同，再恢复原有类型响应。get_run另外核对请求RunId、冻结输入和计算前沿，旧Run允许不同于当前草稿修订。原有managed_assets在解包后按原get_task渲染结果独立关联，不能用JSON附件放宽图片句柄授权。

读取成功、取消、短读、JSON/类型/身份不匹配均关闭已获授权的己方句柄；不得关闭未认证帧里猜测的数值。收到响应前传输失败时Host回收已复制而未交付的句柄；桥退出由OS关闭己方句柄。临时文件在本次读取结束或连接清理后删除；运行记录及原冻结输入保留。读取取消是传输取消，不生成计算Task，也不取消、删除或改写原Run。清理失败须报告实际文件错误，不返回假成功。

## 人工与Agent消费者

ui_host的typed客户端统一解包：本地Tauri invoke直接返回原有Response<R>，不因命名管道的1MiB限制强行走文件；各功能面板只消费原R。Bridge统一处理managed，不要求每个Agent工具另写读取逻辑。MCP structuredContent保留小的有类型外层响应，同时以EmbeddedResource(application/json,text)携带完整原Response<R>，URI使用superfactory-result://<result_id>作为本次内容身份，不提供任意路径读取或新的resources/read接口；接收方解析嵌入文本后取得原R。不得只给一个无法读取的链接。MCP调用取消或输出失败不把部分文本标成成功。完整MCP stdio内容不继承本地管道帧上限，实际客户端支持仍由原产品接入验收取得。

版本仍为未实现产品的API 0.1、IPC 1；没有已发布客户端兼容迁移。保存的Project/Run文件格式1.0不变，managed引用/句柄不得写入工程包。若后续已发布协议再改变，以协议版本策略处理。

## 验证与适用范围

tools/type-contract-proof的AQ-01试做实际编译公共Rust、派生Schema/TS，构造3000物品/3000事件的完整类型响应，验证大响应与小帧、原生和标准Schema正反例；另在自建临时文件与子进程间实际复制只读句柄，核对完整字节、禁止写入、短读、取消、断连及解包失败清理。该有限传输试做不实现产品Host/Engine或实际Codex客户端；产品接入按同一合同验收，不再猜传输格式。
