# 纸包装结构生成与全过程判定（S06-04）

本规格修正F64-01至03，数值及制造消费[数值与制造规则](纸包装数值与制造规则.md)，局部字段消费[接触与连接契约](纸包装局部接触与连接契约.md)。[算法JSON](../../packages/packaging/algorithm.design.json)记录执行决策；唯一公共类型仍为[types.design.rs](../../packages/domain/types.design.rs)，调用入口仍为[18操作契约](公开操作与宿主调用契约.md)。本轮只有隔离方法试例，产品内核未实现。

## 输入、拥有者与输出

人工/Agent提交同一修订的`PackageStructureJob`；Commands按既有scope/input_revision与显式预算冻结输入，packaging负责本规格的候选和几何计算。Job内材料、接触许可、产品版本/包络和动作来源必须明确。结果是`PackagingResult`与逐目的`PackagingCheckResult`、证据区间和制造资产。人另行认可、工程另行绑定、simulation另行改变库存；本算法不产生工厂物品、生产时钟或人的决定。

所有被请求的成型、净空间、开合、固定姿态直线取物、制造检查均完成才能给该用途Pass。单个候选有证据违反硬条件为该候选Fail；缺输入、未知能力、数值/预算未收敛为Undetermined。输入格式/域错误使用既有Host输入错误，不能误写成产品物理不可行。部分图层/候选可以保存，不能充当完整成果。

## 可执行几何和坐标

`PanelDefinition.polygon_mm`为局部XY有限、简单、正面积多边形，厚度沿局部Z。单板当前载体没有洞；非凸轮廓剖分为凸单元，不能整体凸包填掉凹口。front为`Z=t/2`，back为`Z=-t/2`。`flat_pose`把板局部坐标映到所属part展开坐标；`part.placement`再映到Job世界。全部包装尺寸使用mm和已声明右手Z向上坐标，边界显式转换一次。用于几何计算的Pose.scale固定为1，变尺寸修改实际多边形/厚度；视觉缩放不能替几何。

FoldBand的axis_start/end在panel_a局部坐标；panel_a是父，panel_b是子，轴必须非零，child不能有两个自由父，根由PackagePart.root_panel明确。同part每块板属于同一有根树；额外固定连接属于闭合约束，不添加第二个自由父。宽度是人认可的局部压痕带参数，轴/板偏置已在几何里表达，禁止统一“加一倍厚度”。弯曲纤维实体、损伤和应力不在本板片运动学模型内；要求这些内容的用途不能由本几何Pass关闭。

在q=0时：`T_i=part.placement·flat_pose_i`。父子初始关系为`T_ab(0)=inverse(flat_pose_a)·flat_pose_b`。折角q后的关系为：

`T_ab(q)=Trans(axis_start)·Rot(unit(axis_end-axis_start),q)·Trans(-axis_start)·T_ab(0)`。

从root逐级相乘得到每块板真实姿态。分支共享祖先运动，不能将子板独立套直线TOI。已有连接帧和所有局部许可随同一真实板变换。

## 一个动作怎样执行

步骤先检查prerequisites无环，以输入steps顺序作稳定拓扑排序。每个动作完成才进入下一步，不偷偷并发或变更原顺序。每段参数s覆盖完整闭区间[0,1]，duration_hint只供呈现，不产生工厂耗时。

|动作|具体语义|执行前/后必须检查|
|---|---|---|
|Fold|目标fold_band的q(s)=from+(to−from)s；其他关节保持前一步值，所有后代随树运动|from与当前角匹配，整段在allowed_range内；终点、许可区及生效连接均检查|
|RigidTranslation|目标part从start_pose沿世界displacement作固定姿态直线运动|start_pose匹配当前根姿态；part全部板及跨part障碍参与|
|RigidRotation|目标part绕世界pivot/axis插值from/to角，其内部树关系保持|非零轴、全段真实根变换；与其他part及已生效连接一起检查|
|FixedPose|`FixedPoseMotion { part_id, pose }`选择Job内构件，校核当前根姿态并保持，不瞬移|保留该构件当前关节角/树变换；未知目标按InvalidInput拒绝，合法输入中的明确姿态不匹配为专业Fail；仍检查构件/产品及生效连接，数值未定保持Undetermined|

复审窗口2已将FixedPose目标修正合入唯一Rust源，并生成公共Schema/TS。公开计算请求和PutPackagingJob共享该载体；本窗口的[六项有限保持预期及三种错误形状检查](../../tools/packaging-algorithm-proof/output/fixed-pose-result.json)直接读取当前生成Schema，不调用Host。保持动作不重置内部折角；关节变换依照当前树状态。

## 局部许可的实际判定

一条LocalContactAllowance是同一ID的一对板面区域，不是板对豁免。对板A的选定面多边形PA，设批准法向深度d=`normal_overlap_limit_mm`，须0≤d<min(t_a,t_b)，不截成t。构造局部许可体：

- front：`PA×[t/2−d,t/2]`；back：`PA×[−t/2,−t/2+d]`。
- 板B同理。深度是各自指定板面向实体内部的距离，不是世界Z，更不是Parry distance=0。d=0只有已证明的该面接触可以许可；数值死区不提供额外穿透。
- 所有patch必须真实位于对应板面，且当前step在active_step_ids内；许可集合为空就没有许可。每个板对/当前步骤把所有许可区域联合后，两板仍须留有正体积未许可残余；整板厚度或联合覆盖整板应拒绝，不能用多ID造整对豁免。无对应步骤ID、负/全厚度深度、越界或联合覆盖整板是输入域错误。

按全部有效区域边界及深度层，把板棱柱分割为凸单元，单元附所属许可ID集合。裁剪/区域归属不确定不能扩大单元标签。接触双方单元的标签交集中存在**同一有效许可ID**，该单元交集才在双面许可体内；A属于L1而B属于L2不合格。其余单元对照常检查全程分离。不同step重新计算有效标签，不能沿用上一段许可。

该分解把“任何相交必须在两块匹配区域和批准深度内”化成有限单元对条件。对非凸区域需要可靠平面分割；没有完成的形状裁剪只能Undetermined，不能用patch包围矩形放大许可。分割边界附近的未定接触保留未知，不能把闭单元边界重复造成的零距离叫穿透。初始隔离试例只实现矩形；RR-W3-01已修复公共Job方法读取器扩大三角形许可的问题，新增精确有理耳切三角化、按真实patch边界平面分割及深度层标签，包含凹板/凹区且不填凹口。新增方法限有限简单无洞多边形的局部恒姿态平移适配器，不等于任意Job、全部铰接过程或通用制造实现；[修前/修后和12项独立预期](../../tools/design-quality-audit/report-linked/window3/polygon-cells-result.json)据实记录。

## 连续区间：如何证明，而非采样猜测

对当前步骤区间I，各板真实关节角、平移及矩阵逐级作包含真值的区间运算，得到每个凸单元顶点在全区间的包围。首先选择世界轴、参考姿态面法线及必要边叉积作为候选分离轴。候选轴可以是确切存储的任意非零向量；不必假装它等于精确法线。对该轴逐顶点投影并取区间上下界，**先投影顶点，再取范围**，不能先做世界AABB后丢掉旋转相关性。

若存在轴n满足：`projection_gap_lower > clearance·||n||_upper + numeric_deadband·||n||_upper`，该单元对在整个I分离。隔离程序用轴L1范数作欧氏范数的保守上界。只有来自这个界的结论才跳过全区间。

也可使用已认证的参考距离下界d_lower和位移界：

`δ_i(I) ≤ Σ_祖先e R_ie(I)·max_{s∈I}|q_e(s)−q_e(s0)| + 全部祖先/本体平移位移上界`。

其中R_ie以局部顶点范数上界、全路径固定偏置与该区间平移上界之和构造，必须覆盖整个区间。`d_lower > δ_i+δ_j+clearance+deadband`才支持安全；Parry返回的名义distance没有误差证书，不能直接当d_lower。

不能证明分离时，在端点/中点或库建议的时点找候选交点，再独立验证它严格在两个禁止单元内部、到边界超过比较死区；这才是Fail证据。样本没碰撞不是Pass。没有Fail证据则左区间优先二分；全部叶区间有分离/局部许可证明才Pass。区间/细分预算结束为Undetermined，附未覆盖区间。静态边界在时间细分下不收紧时直接保留未知，避免重复无收益二分。

已取得的有限证据见[预期](../../tools/packaging-algorithm-proof/finite-expectations.json)与[实际结果](../../tools/packaging-algorithm-proof/output/proof-result.json)：KIN01的两端分离，中点严格碰撞；KIN02连初次0/0.5/1采样都漏检，在6次细分后于s=0.28125找到(2.4,0.7,0)严格内部证据。它证明本方法可检出这些过程反例，不能外推为所有铰接过程已实现。

## 固定连接：何时激活及如何保持

`engage_after_step_id=null`表示初始已连接，先验证两world frame位置/角度闭合。其他连接只在所指成型步骤**完整过程通过且终点闭合通过**后激活，先后的许可active_step_ids仍独立控制。不能仅看step完成名字就增加约束。

激活后，后续每个区间继续检查`T_a·frame_a`与`T_b·frame_b`闭合。位置差界按距离阈值；方向以相对旋转矩阵的弦距离作包含界（`||R_a−R_b||_F=2√2|sin(θ/2)|`），不用不受控acos值猜角度。明确超限为该动作Fail；跨阈值仍细分/未知。连接不变成自由铰链，也不反过来吸附/变形板片来制造成功。闭合运动没有给解，不能为闭环补任意姿态。

## 三机制、空白创作与三变化

结构生成由下列实际操作组成，输出同一个可编辑Job，不另建专业类型：新增板、添加有向折带、添加具名局部固定连接、添加/显式复制part、编辑现有尺寸/条件、重排真正独立步骤。模板参数只用于编译这些操作，不把结构封成不可编辑长宽高表。

|入口|实际构造及过程|硬条件和修改接点|
|---|---|---|
|受限折叠容器|底、壁、翼板按认可平面几何建立有根板树；逐折带Fold成型；声明的开口板反向Fold打开|板/轴/带宽/偏置/局部许可完整；净空间和完整形成/开合过程；可增改翼板/关系|
|外盒与内衬|外盒、内衬各自板树及独立part；内衬按显式placement/插入平移装配；需要时另激活固定连接|所有跨part板对和产品包络参与，不只分别检单件；材料/姿态/间隙及连接关系可变|
|罩/滑套|罩用受限板树；滑套用声明四壁/闭缝，接缝按局部胶区激活；独立part平移/旋转作开合|闭缝保持、套/罩完整路径及产品固定姿态取物；没有任意运动规划|
|空白受限结构|不注入盒型；用户从上述同类操作生成自己的Job|缺材料、可执行结构或动作就定位缺项；不能缩成只修改固定盒尺寸|

产品/功能变化改subject_ref、包络/认可姿态/条件及约束；认可材料变化显式改材料与对应板厚，重验折带/许可/展开；构件关系或重复订单变化改树/固定连接/步骤或显式复制part。新ID与引用一起生成，重复件真实出现在Job，不能以订单目标冒充材料数量。

## 变量和有限搜索冻结

白名单路径在算法JSON列明：现有ID板的顶点坐标/厚度、折带宽度/目标角、part位置、产品余量和取物距离。先按ID定位，再解已有顶点下标/数值叶子，单位mm/rad/integer与范围一致。定义改变导致数组重排后必须重绑；不把任意JSON路径作为代码。改材料厚度要显式更新认可材料和受影响板，不能为过检查擅自减薄。

每个实变量有限值包括当前合法种子、min/max/中点、硬约束target及目标邻近的可表示值；落范围且满足比较关系后去重。整数变量按范围内所有整数升序懒枚举，预算不到不能叫穷尽。结构候选限于明确选定种子、显式操作形成的有限图及prerequisites允许的拓扑顺序；不自行加胶或删人要求的板。依次按种子输入顺序、结构/步骤稳定顺序、变量ID和数值排序，笛卡尔积懒生成。

每候选检查：解析/材料/区域/轴→尺寸硬条件→初态/成型→连接激活端点→净空间→开合→固定姿态取物→制造。某硬条件有明确反证可剪掉**该候选**。完整候选通过即可交付其具体模型及搜索范围；零候选、有未知、预算未覆盖或连续尺寸范围未穷尽，整体为Undetermined，不能声称全球所有结构无解。没有混合量纲“质量总分”，也不要求无界优化。

## 产品包络、净空间和直线取物

产品vertices形成认可的保守凸包，每个allowed_pose是明确允许选择。净空间在所选姿态把完整包络与所有相关板实体作包含/间距检查，不用只比较外部长宽高。包络通过只支持认可包络与指定姿态；包络失败不证明真实复杂物体所有姿态都不能装入。

取物使用ExtractionPlan.product_pose固定，沿单位direction移动distance；part_ref定位包装对象而不删除其他相关内衬/罩障碍。全闭区间使用上述证书，Parry线性shape cast可给候选时点，但不能遗漏初态、终态、局部许可或输入缺项。旋转取物/自动路径规划保持不支持，返回明确范围。

## 实施接点和证据界限

packaging消费公共Job/API，输出公共Result及文件；module-kit/专业工作台编辑同一结构和来源；Commands冻结修订/预算；presentation只看真实过程姿态；reporting保存结果、未知和制造版本。实际Rust依赖/锁、共享字段及全部消费者由W00整合，当前只隔离证明，不安装库或触碰这些文件。

设计方法有明确执行步骤、32个原有限预期和新增六个保持姿态预期的实际结果；FixedPose目标载体已合入，通用多边形裁剪、完整Rust几何向外舍入内核及全部三机制整合尚不能宣称已运行。复审/共享合入状态见[S06-04报告](../04_开发与验收/S06-04_纸包装算法与数值方法复审.md)。

## 具体结构程序与字段绑定的实际试做

[有限种子程序](../../tools/packaging-algorithm-proof/construct_seeds.py)已实际生成三个机制及三个变化的六份公共Job，Schema全部通过；几何过程未因此取得Pass。这里的值是明确自建输入，不是产品运行默认参数。实际模板必须取得L/W/H、认可厚度t、带宽f及placement/产品条件，不能缺值就注入本例。

基础blank程序的底板局部范围为[0,L]×[0,W]；前/后壁分别是L×H，flat_pose为(0,−f−H,0)/(0,W+f,0)；左/右壁为H×W，flat_pose为(−f−H,0,0)/(L+f,0,0)。其轴在BASE局部：前y=−f/2、后y=W+f/2、左x=−f/2、右x=L+f/2；四段覆盖对应有限板长。前/后角是−π/2/+π/2（沿+X轴），左/右角是+π/2/−π/2（沿+Y轴）。f>t只作为这个明确种子给板实体留出间隔的几何前提，不是纸材定律；不满足时不能偷改f/t使之通过。
