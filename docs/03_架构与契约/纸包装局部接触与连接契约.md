# 纸包装局部接触与连接契约

S06-04现行局部接触设计；完整专业几何与共享复审尚未通过，有限方法证据列在下文。唯一字段取`packages/domain/types.design.rs`，不复制第二份专业类型。

允许接触现在是两块板的指定正/反面、各自局部XY毫米多边形、允许法向重叠量、适用过程步骤和输入依据。面积之外仍参与普通干涉检查；`allow_contact`不能豁免整对板。每块区域必须实际位于对应板面，未知边界或计算预算不足仍是未判定。

固定连接明确局部许可区域引用和生效步骤。未指定生效步骤代表初始装配已经连接；指定时，仅在对应成型步骤成功结束、连接帧满足闭合容差后生效。后续不能把同一连接继续当自由铰链。缺少胶区不能从两连接帧猜出胶面积。

刀/折/胶制造资料消费同一个实际结构和局部区域。旧ID对设计输入必须在PREP-PACKAGING中明确补区域/允许量，不自动放大成整面许可；空接触列表保留为空。

现行区间方法已在[结构与过程算法](纸包装结构与过程算法.md)落实：按每块指定面区域向本体内部的批准深度构造许可柱体，分割板实体并以同一个有效双面ID给单元标记；剩余单元全区间照常查分离，不能用A的L1加B的L2凑许可。数值/裁剪不确定与预算不足仍是Undetermined，不扩区域。

非空公共Job已通过现行Schema并实际用于PUBLIC01隔离区间检查；实际接触/终点连接与共同胶投影100mm²及SVG来源已验证，见[结果](../../tools/packaging-algorithm-proof/output/proof-result.json)和[SVG回读](../../tools/packaging-algorithm-proof/output/svg-readback-result.json)。这是矩形patch/简单棱柱与指定平移的有限方法证据；通用多边形、完整Rust专业算法和工业胶接未因此通过。

面接触载体限定0≤批准深度<两板实际厚度最小值，不默默截成整板厚度。对当前pair/step区域联合后，两板都须有正体积未许可残余；LC12/13实际拒绝全厚度和多区域联合整板授权，不能由多个ID构造整对豁免。
