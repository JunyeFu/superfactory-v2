# S04可操作设计原型

当前入口：[打开原型](http://127.0.0.1:8921/)；本机只监听127.0.0.1，端口已登记。当前服务由复审窗口2启动，页面修改后刷新即可。服务停止后，用现有Python运行本目录的`serve.py`；启动前仍核对全局端口表。不需要安装依赖。

这是受监督设计批次的隔离浏览器原型，文件仅位于docs/02。没有创建产品apps入口、Rust Engine/Host或外部Agent，也没有恢复Figma。菜单、输入、画布、状态控制、文件下载和重开在浏览器中实际执行；业务区间和数量读取手工预期，不计算任意修改后的工厂产能。

## 可以操作的内容

- 流水线和多厂房两画布、详细/简化/区域三档；点击设备或区域成员进入配置，滚轮不进入详情。已有六类自建GLB的同设备背面、底部、近景可查看；区域聚合保留成员身份。
- 新建空工程、订单/到料输入、自定义九类定义草稿；模板采用明确新ID、资源复用、供料和订单选择。取消不改变工程，基础修订冲突不部分采用。原型定义不产生库存、人员或专业求解能力。
- 时间轴和描述区由“窗口”菜单分别显隐；底部默认160px，拖动调高与左右调宽可操作。输入联动、预览、Esc取消、一次提交、回看定位、裁窗保真区间、返回保留主动选时、迟到回复拒绝与截断快照替换有有限例。
- H04-04的32字段/6状态在目标页展开查看；缺高度可保存原型草稿，目标预览明确缺项。初案成功直接交付、无变化停止、最多三次修正、越权候选整体拒绝都是已标注的manual/type_fixture交互分支。
- 纸包装输入和折叠角会改变图示；step/u/panel_id与局部Pose示意不等于工业求解结果。当前五板片显示代理不完整替代三种机制的专业模型。Pass/Fail/Undetermined、用途认可、绑定、改版待复核的交互已接通。
- 四格式说明使用同一份设计数据；每份样例保留冻结输入与观察边界，成本缺费率明确未知。HTML/CSV/JSON真实下载；PDF通过浏览器打印为PDF。原型JSON能实际下载、重新打开和继续编辑，图片/GIF数据随原型快照保留。
