## 连续任务与阶段职责

- VF-01 空工程搭线/到料/等待/比较交付：VP01 → VP02 → VP03 → VP05 → VP09 → VP10 → VP11 → VP12 → VP13 → VP21 → VP22 → VP23。
- VF-02 设备渐进创作与同一行为采用：VP03 → VP04 → VP06 → VP05 → VP07 → VP08 → VP24。
- VF-03 目标建厂分支：初案达标为 VP14 → VP15 → VP05 → VP11 → VP16 → VP22 → VP23；不足才进入 VP17，再选许可变更/重跑比较或无法修正说明。VP16不得强制经过VP17。
- VF-04 完整纸包装结构/过程/制造/绑定：VP18 → VP19 → VP20 → VP05 → VP22。
- VF-05 跨厂/比较/接手/再修改：VP09 → VP11 → VP12 → VP21 → VP22 → VP23 → VP24。

24帧可共享组件/资产，不是24个独立工作空间；只存在两常态画布。专业/比较/报告为同工程工作台，关键任务的返回、可改输入、缺项/冲突/取消与初案达标直交不能剪掉。
