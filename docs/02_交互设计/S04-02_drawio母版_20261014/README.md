菜单/工具/字段/表格/标记/连接/弹层均为原生可编辑元素。场景图嵌入文件，重开不需网络；仅它是AI插图，不能当作真实三维模型或设备尺寸证明。AI场景由内置GPT从v03生成，逐字UI不交给生图。

页链接只用于查看设计状态，不实现真实拖宽、字段提交或业务计算。母版不替代24帧五条业务链、S04-04原型、S04-05本人走查或产品实现。

M20的A01是多阶段工艺，当前只编辑auto阶段的归一化u；M25提供全部阶段绑定。单阶段且正工时已知时才允许cycle_normalized。区域档只聚合既有LINE01，未编组的B01/B02/FG01仍独立；简化/区域是原生矢量示意，真实软件依现行3D渲染要求实现。


## 当前布局

顶部菜单、底部工具。时间轴/描述独立，默认高160、描述宽300；主轴展开和细化例高320。窗口菜单管理显示/隐藏，视图菜单管理相机、LOD和时间缩放。组行40、设备行32、行名240，输入/实际/对比有独立来源；选择与时标不因隐藏而改变。[顺序导出源](export_master.py)等待每次实际导出，避免旧图混入。

当前设计依据：[主轴与子轴完整定义](../时间轴主轴与子轴完整定义.json)、[36项监督选择](../时间轴主轴与轨道组_监督细化.json)、[设备表现设计](../设备时间轴与标签设计.md)。M16数值来自DTC02手工预期；M18来自E04手工输入；M19是独立跨厂UI示例，均不是工业观测或已跑结果。当前尚未产生的实际阶段/等待结果，M17用缺项明确呈现，不按名义工时补出生产条。
