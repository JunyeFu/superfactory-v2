# 九类贡献的分别入口

本表对应原P5-01步骤1及`community/templates/README.md`。路径相对软件工程根；候选列相对本轮`.inputs/candidate85/`。设计manifest只表示设计例子，候选包存在只表示实际携带声明，两者都不替代导入／预览／明确采用／类别消费者运行或第三人贡献证据。

|类别|既有设计入口|candidate85内实际入口|接收关注|
|---|---|---|---|
|物品 items|`modules/items/shell-spec/manifest.json`|`modules/devices/template-support/items/module.json`|规格、单位与合法表现；定义不携带库存身份|
|固定设备 devices|`modules/devices/control-box-assembly/manifest.json`|`modules/templates/purchased-assembly/candidate/definitions/Assembly01/module.json`|端口、阶段、设备作业及表现来源；原生场景授权仍待确认|
|资源 resources|`modules/resources/operator-role/manifest.json`、`modules/resources/power-source/manifest.json`|`modules/devices/template-support/resources/module.json`|容量／单位与占用语义；不导入别的工程当前占用|
|任务 tasks|`modules/tasks/board-preparation/manifest.json`|`modules/devices/template-support/tasks/module.json`|任务定义与业务输入边界；不把模板目标当实绩|
|工艺 operations|`modules/operations/control-box-rule/manifest.json`|`modules/devices/template-support/operations/module.json`|输入输出／阶段与规则；独立预期明确|
|物流 transport|`modules/transport/batch-transport/manifest.json`|`modules/devices/template-support/transport/module.json`|批次／运输与目的接受；不更改真实持有关系|
|厂房模板 templates|`modules/templates/parallel-electromechanical/manifest.json`|`modules/templates/parallel-electromechanical/candidate/module.json`；另有纸箱、机加工、采购装配三模板|依赖版本／参数来源；导入不等于实例化，不带在制|
|专业 professional|`modules/professional/machining-producer/manifest.json`|`modules/devices/template-support/professional/module.json`及catalog中的专业声明|专业输入输出、适用范围与消费者绑定；不是所有专业方向均已实现|
|美工 media|`modules/media/editable-bench/manifest.json`|`modules/media/p302-line-grade/installable/assembly/module.json`；另有p302-controlled与p303-owned|GLB／图片／动画的精确版本、节点／动作／素材许可；测试例不冒充工业质量认可|

候选JSON实际包含九类声明，原文位置与JSON指针在`assets-and-rights.csv`。定义作者／许可、asset来源／许可／redistribution_confirmed、包级rights一致性和文件存在性分别核对。模板与support的unknown不会由其他CC0/MIT包覆盖。

贡献流程沿用`community/templates/README.md`及既有Issue／PR规范：提供精确包、来源与修改说明、独立预期和可重开例子；维护者审查权利及类别契约；用户预览后明确采用；相应消费者实际检查后接收。参与人数、第三人操作、PR与公开发布据实另记，本轮不补写。
