# C15 常见问题

适用范围与完整步骤见 [普通用户操作说明](C15普通用户操作说明.md)。

|遇到什么|先怎样处理|
|---|---|
|目录选择器里找不到project.json|“打开工程目录…”选它所在的整个目录；只有“打开工程ZIP…”才选ZIP文件|
|运行按钮灰色|先创建／打开工程，回到输入草稿，选择当前方案；完成本地表单检查／应用，并等当前操作结束。按界面给出的能力或缺项说明处理，不连点|
|采用模板后没有库存或订单|模板定义不自动制造库存。创建示例方案、供料、订单、初始质量和检验预设是分别确认的输入；返回配置核对，不能把空白理解成无限供给|
|图上已经有设备，却无法生产|检查工艺路线、物料连接、角色资源、日历、初始物品及质量输入；画面位置和模型本身不提供生产规则或工时|
|修改输入后，旧结果没变|这是正常的冻结结果。确认应用草稿，再运行新Run；回看旧Run仍读旧修订|
|4000看起来不是4秒|时间轴与实际过程时点使用毫秒。输入4000后点读取时点／重读实际来源，并等观看时点更新|
|设备加工100%却不交接|可能仍等待输出空间、接收或其他条件。看事件、等待原因和物品持有者；加工完成与最终接受不同|
|画面没动或没有模型|先区分声明预览、冻结静态检查和实际Run，再核对是否有唯一活动作业、声明动画和所选详细／简化／区域档。没有声明的档位或几何会明确不可用，不自动补模型；未显示不等于物品丢失|
|观察值已改，画面仍是上一刻|读取可能尚未完成。以界面“正在读取／观看”的实际时点为准，等更新后再判断|
|同一物品出现多处记录，能否相加|不能。沿同一身份核对持有者；组成、容器内容和接受量按各自单位解释，不把记录条数当产量|
|提示方案参数覆盖不支持|本版独立方案覆盖尚不支持运行。按提示清除不支持项；要改设备实例参数，用“设备阶段与参数”，应用并明确重跑|
|请求取消后仍完成了|取消与完成有先后边界。读取实际终态和结果，不把“已请求取消”当已取消；播放暂停也不是取消计算|
|提示工程修订已变化／RevisionConflict|保留本地表单，读取当前工程并核对差异，再明确重新检查／应用。不要自动覆盖或重放上一次提交|
|保存失败、拒绝访问或文件被占用|保存不能记为成功。保留当前工程，按实际错误检查目标可写性和占用，明确选择合适目标后再保存；不要强删原工程、锁或失败证据|
|保存后标题仍有星号|检查是否有未应用输入、未提交定义草稿或保存期间产生的新修订。“已保存 r…”若同时提示仍有新修订，继续处理并保存|
|搬移后无法打开|确认搬的是软件已正常关闭后的完整保存目录，不是单个清单或结果；资源、模块和子目录都应跟随。缺项草稿可以保留，但不冒充完整可运行|
|专业计算已完成，为什么还是未判定|任务结束只表示计算结束；Undetermined仍是未判定。Fail也不能因录了人工说明就改成Pass|
|专业成果已认可，为何工位仍没用它|用途认可与工位采用绑定分开；核对精确产品／成果／输入版本，明确选择工位输入并提交绑定，再计算新的工厂Run|
|成本为空，是否就是0|不是。未知价格、币种、完整总成本或未完成时间保持未知，不能用0补齐|
|目录包用户要装Rust／Node吗|普通运行不需要；需完整C15目录和WebView2。只有从源码开发／构建才需要相应工具和锁定依赖|

若继续报错，交接给维护者：应用候选、完整工程副本、实际错误文字、所选方案／Run及观察时点、刚才的操作。先保留已有结果，不用新的运行覆盖原问题。
