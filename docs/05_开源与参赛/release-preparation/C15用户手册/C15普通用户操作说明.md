# 超级工厂 C15 普通用户操作说明

适用：应用0.1.0／C15目录候选。你可以先读已有工程，再用模板或明确输入生成新方案。本说明依据固定C15源码和既有接收记录；本批没有启动软件，C15完整普通窗口接收与新视频仍待维护者确认。

## 1. 准备软件，打开工程

保留完整Windows目录，从其中打开 `superfactory.exe`。需要WebView2，普通运行不需要Rust或Node。先把 `demos/missing-material/` 整个目录复制到你自己的可写位置练习，不直接改唯一原件。

点击 **文件 → 打开工程目录…**，选择包含`project.json`的目录。工程ZIP用旁边的 **打开工程ZIP…**。在 **打开工程 · 采纳前核对** 中核对缺项、冲突和版本，再点 **确认打开**。选择“保留缺项，以可编辑草稿打开”只允许继续补输入，不表示已能完整运行。

已有工程时，先保存需要保留的修改，并处理未提交定义草稿。“离开当前工程”可选 **工程已保存、定义已提交，继续**；有本地未应用输入时返回处理。不要为绕过提示随意选择放弃。

## 2. 先阅读随包的旧结果

在画布上方 **未选择 Run** 下拉框选择缺料工程的保存结果；进入 **实际回看**，左侧应显示 **Run 冻结输入**。不用点“运行方案”。密集工程也有自己的保存结果，不能用一个工程的时点解释另一个工程。

|目录|应选择的保存Run|
|---|---|
|`demos/missing-material/`|`B60-105-missing-material-50268:run:1:2`|
|`demos/dense/`|`B60-105-dense-47464:run:1:2`|

在 **窗口** 菜单显示“时间轴”“事件描述”；需要时用 **恢复默认布局**。时间轴选择 **实际**，输入观察毫秒后点 **读取时点**。`1500`为1.5秒，`4000`为4秒；**播放回看／暂停回看**只控制观看。**返回当前**读取已计算前沿，不是继续生产，未来没有计算的数据不能推断。

缺料工程的保存数据可作以下对照：

|时点|应核对的实际含义|
|---|---|
|1500 ms|所需物料尚未在3000ms到达，等待缺料；不要套用旧日历案例“物品在源位置”的画面|
|4000 ms|D01在3000—5000ms的cycle中，已用1000/2000ms，即50%；该物品由D01作业持有|
|5000 ms|同一物品经缓冲交给D02作业，D01释放容量；这不是最终产品接受|

缺料结果前沿10000ms；密集结果前沿1200000ms。两者设备样例为1.0.5，冻结工程修订6。表中是保存结果含义，不是本批新截图或新运行验证。

## 3. 看设备与同一件物品

选设备，点击 **设备过程 → 所选设备的过程…**；若事件描述提供 **查看所选作业过程**，优先从该作业进入。确认来源是实际Run；“声明预览”只展示声明动作，不能当作实际作业。

设备过程可填写 **实际观看时点** 并用 **重读实际来源** 刷新。先等画面提示的观看时点与输入一致，再看“阶段与持有”、资源、物品身份及实际持有者。显示正在读取时，旧画面不等于新时点已经返回。

沿同一物品身份查看：它可能由源库位、当前作业或下一作业持有。切到下一设备或物品记录核对去向，不用“模型暂时没显示”判断丢失。物品组成、容器内容和接受量有各自单位；不能把容器数、工件数和多处显示累加。加工100%仍可能等待输出空间，不等于已交接或已被客户接受。

回到 **输入草稿** 可看当前工程，**实际回看**保留选中Run的旧冻结输入。修改草稿后，旧Run不会自动变成新参数的结果。

## 4. 从模板建立一个可编辑方案

1. 起始页选 **从模板开始**，填写工程名称后 **创建**；已有工程则先处理离开选择。也可用 **模块与模板库**，类别选模板，核对卡片的精确版本和缺项。
2. 在 **配置模板实例** 中填一个新的对象前缀。逐项选择新建模板声明资源，或明确复用已有资源；复用不会凭空增加人手或容量。
3. 需要路线示例时勾选 **导入模板产品、物料清单与工艺示例**。有真实场地数据时再勾 **填写实际场地尺寸**，X宽、Y进深和净高单位为米；没有数据就保留未填，不把模板尺寸当现场适配通过。
4. 要运行示例，再明确勾 **明确创建模板示例方案输入** 并填新方案标识。供料、订单、检验预设分别选择；选供料后逐项指定初始质量。批量填写质量只是明确给列出的输入赋值，仍可逐项修改，不等于实际检验合格。
5. 点 **预览创建对象**，查看新对象、资源、换型规则和方案输入摘要；确认后点 **确认采纳模板到工程**。修改配置后应重新预览。未选择的库存、订单或检验结果不会自动补齐。

四模板（采购装配、机加工交付、并行机电、纸箱）已有C14普通Native的完整修改／运行／保存重开记录；其语义界面在C15未改。机加工与机电工序是声明示例，纸箱场地可能仍未知，不因能运行就成为行业实测或专业认证。

## 5. 填输入，再运行新方案

打开 **业务输入**，选择现有方案，或点 **新建空白方案／复制为新方案**。先核对 **方案与观察窗**，再按任务补齐物品、到料、任务订单、路线、日历和资源。普通字段可先留在表单中；**检查变更 → 确认应用草稿**后才进入工程，关闭表单不会自动应用。

|关键内容|填写和阅读口径|
|---|---|
|释放、到达、交期、观察窗|毫秒；释放不等于实际开工，交期未知不要补0|
|数量、容量、工时|按旁边声明单位填写；piece与批次／容器、秒与毫秒不能直接混用|
|厂房及设备布置|厂房宽／深／高、占地使用米；纸包装结构另用毫米|
|初始物品／后续到料|只定义新方案起点与未来输入，不改旧Run中的实际库存|
|人员、共享资源与质量|选明确角色、资格、容量、日历和版本；质量未知保留待判，不自动合格|
|方案参数覆盖|本版独立方案覆盖不支持运行；按提示清除不支持项，实例参数用“设备阶段与参数”，保存后再重跑|
|目标与成本|目标不保证实际接受；价格未知保持空，不把不完整费用拼成完整总成本|

回到工作台 **输入草稿**，选择 **当前方案** 后点 **运行方案**；也可在业务面板用 **从初始输入重跑**。等任务实际结束，再选择新Run看结果。每次运行从该方案的声明初始条件计算，不从你当前观看的4000ms接着生产。取消用 **取消计算**，等实际终态；请求取消不保证抢在完成前生效。遇缺项、失败或修订冲突先读原因、保留输入，刷新核对后再明确操作，不连续重复点击。

需要报告时进入 **评审与交付**，选择 **评估报告**，核对所选实际Run或设计说明、指标和接受范围，再选择真实输出目标。PDF／HTML／15张CSV／JSON来自同一报告，导出完成状态与文件实际可读分别核对。单Run不要求强加比较；比较时必须使用各Run的冻结输入及可比条件。

## 6. 专业成果与工厂结果分开

**专业工程 → 纸包装 · 结构与过程…**处理已支持的受限结构／过程：先保存输入，再点 **计算已保存输入**。结果为 **Pass · 通过／Fail · 不满足／Undetermined · 未判定**，完整计算任务结束不等于所有检查通过。

若要让工位使用该成果，先核对产品／成果版本与用途，**确认并记录用途认可**，再为实际工位选择对应执行输入并 **单独提交此工位的采用绑定**。计算、认可、绑定和新工厂Run各自独立；改变产品、输入或成果后要按诊断复核，不把旧Pass自动移到新版本。SVG／材料数量是实际制造输出，不代替材料强度、防护、现场工时，也不承诺任意CAD文件均可处理。

## 7. 保存、搬移重开，再继续修改

1. 处理所有未应用的表单输入。定义草稿须在定义工作区提交需要保留的版本，保存工程不会代替这一步。
2. 点 **文件 → 保存工程…**，选择保存目录；等到 **已保存 r…**，并确认没有“当前仍有新修订未保存”。记下工程位置、原Run与要核对的物品／时点。
3. 正常关闭。若出现 **关闭工程 · 尚有未保存内容**，选 **留在当前窗口**处理输入，或 **保存工程后关闭**；确实要丢弃才选放弃。任务处理中先等完成或读取取消终态。
4. 软件退出后，用文件管理器搬移刚保存的**整个工程目录**，包括清单及全部子目录、模块、资产和结果。软件目录与工程目录是两件事，不只搬`project.json`。
5. 重新启动程序，打开新位置；重新选择原Run并读取同一时点，核对物品持有与版本。这一步不点“运行方案”。
6. 接着修改时回到输入草稿，应用变更并运行一个新Run；旧Run仍保留原输入。再次保存，给接手者完整工程、新旧Run及实际改动说明。
