# C17 普通用户操作说明

## 从打开到一次结果

1. 从完整Windows目录启动。文件→打开目录，选自己的可写工程并明确采用；也可新建空工程。缺料、密集示例先复制到自有目录，保留原件。
2. 从模板或模块库选择精确版本。模板带入的资源、产品、BOM、工艺路线、种子、质量和准备策略要明确采用；空工程需自行补齐这些生产条件。
3. 在中央画布摆放设备、连接端口，编辑资源、人员和路线。二维与三维只是同一工程的不同观察面；菜单“设备过程”用于看阶段和物品关系。设备外观或动画不会自动声明生产规则。
4. 业务检查后应用当前改动，再明确运行。读取Run ID、项目与场景冻结修订。旧Run只按旧输入解释，改设计后另建Run；独立ScenarioParameterOverride显示不支持时，不能当作生效。
5. 选择运行，输入毫秒并读取该点，或拖动时间轴、播放回看。核对物品持有者、阶段进度、等待原因与资源状态。播放不增加库存，不会重新计算；缺料、日历、排队、输出受阻须按具体条件理解。
6. 缺料示例1500ms缺料；4000ms D01 cycle 50%；5000ms同物品交D02、D01释放。密集例原Run含155994事件、30000作业、3000物品。两例均使用p201.b60.station@1.0.5，与介绍C12日历案例区分。

## 专业、Agent与报告

专业计算区分通过、不满足、未判定。结构成果、用途认可和工位绑定分别确认；可编辑成果和SVG不能替代现实制造／保护性能检验。产品或结构改动后重新核对适用性。

外部Agent通过当前宿主的实际管道／实例连接stdio桥，使用与人相同的查询、检查、编辑和运行接口；MCP配置示例只是示例，不能照抄失效实例，也不代表客户端已配置。Agent不会另开一个引擎，旧Run仍可人工追问。

报告明确选择Run或受限修正比较，核对目标、观察窗、接受位置／单位及允许修改项。C17 PDF增加阅读层，单Run实证10页、双Run16页；JSON／CSV与工程附件仍保留。未知成本保留未知，接受增加不能自动推出完工时间缩短。

## 保存与交接

等待保存完成，正常关闭；复制或搬移整个工程目录，再在新进程文件→打开目录并采用。先读原Run和固定观察点，再修改自己的副本、检查／应用和运行。不要只交截图或单个JSON。
