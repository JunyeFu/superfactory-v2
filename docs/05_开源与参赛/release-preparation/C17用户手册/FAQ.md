# C17 FAQ

**只有EXE能运行吗？** 请复制完整Windows目录，保留modules、report-resources、许可和示例；Windows 11 x64需要WebView2，用户无需Rust／Node。

**为什么画面动了却没新增产出？** 播放和时间轴读取已有Run。修改设计后检查、应用，再明确新建Run，才会重新计算。

**为什么旧Run不跟着新参数变化？** 旧Run保留自己的冻结输入、模块版本和场景修订。用新Run比较，别覆写旧结果。

**缺料样例1.5秒为何不是日历等待？** 随包missing-material案例与介绍C12历史日历案例不同。按当前Run具体等待类型解读。

**如何接手？** 保存完成后正常关闭，交整个工程目录；新进程打开并采用，先读旧Run，再修改副本和重算。工程、结果、模块和素材不要拆开。

**专业通过就能生产或认证吗？** 通过只针对声明的算法输入；成果、用途认可和工位绑定分别确认。未判定和未知成本不能当作通过或零成本。

**Agent如何连接？** 使用当前宿主实际pipe／实例及授权，启动随包stdio桥；配置示例不是自动完成客户端配置。Agent与人工共用宿主操作和仿真内核。

**C17修了什么？** 保留C16资源读取／GLB内存修复，新增报告阅读层。实际Native十页／十六页报告及搬移重开已在冻结Root回执确认；原OOM序列关闭不等于正式NFR全过。

**介绍和视频为何有旧版本？** 介绍保留清楚标注的C11/C12真实图；215秒片为C16真实录制，核心操作与C17保留源码对应。C17新报告页另有导出证据，没有虚构重录。

**已经公开发布了吗？** 没有。代码为本地C17提交，外部评审权限、视频URL和普通播放器未验；最终LICENSE仍未定，保留既有原文／NOTICE／OFL及未知声明。
