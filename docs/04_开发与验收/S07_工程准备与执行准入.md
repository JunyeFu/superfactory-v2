## 实际入口

在`软件工程`产品根执行：

```powershell
npm run generate:types
npm run typecheck
npm run build
npm run test:rust
npm test
```

完整工程验证入口：

```powershell
./tools/s07/verify.ps1
```

首次恢复依赖使用`npm ci --ignore-scripts`、`cargo fetch --locked`；本轮使用实际安装与依赖树、锁文件读回验证了依赖解析，未另做干净机器恢复验收。

`npm run build`先构建Rust工作区，再通过Tauri CLI构建并嵌入本地前端资源；工程阶段使用debug和no-bundle，不输出安装器。Tauri CLI经`-- --locked`透传Cargo参数。不要在已构建本地资源的桌面启动烟测前，单独运行默认特性的`cargo build --workspace`覆盖该exe；统一使用根构建入口保持构建与烟测匹配。

桌面直接启动为`./target/debug/superfactory.exe`；工程测试以`--s07-smoke`参数隐藏启动该真实exe，在React加载和IPC往返成功后退出。桥骨架为`./target/debug/superfactory-mcp-bridge.exe --version`；未实现业务桥时默认启动明确退出，不假装提供MCP服务。

`npm start`已配置为Tauri开发入口，Vite绑定`127.0.0.1:8922`，该端口已在全局注册表预留。本轮没有启动TCP开发服务；实际启动证据来自打包本地资源的桌面exe。开发服务启动前仍需核对端口空闲，现有S04原型8921不受本轮操作影响。
