# P2-01/P3-02 持久化展示槽创作与场景完整消费者续作

继续[P2-01](P2-01_整包执行.json)、[P3-02](P3-02_整包执行.json)原全部4+3步骤、Q、SF/IX/NFR/release。前置取[完整选定方案](../../../scenarios/媒体表现/runtime-item-spatial-source-review/handoff.md)与[实际生产者任务](P2-01_P3-02_持久化物品展示槽完整生产者续作.md)。当前媒体消费者11项已冻源，不能改写其原证据。生产者正式交回前可读新生成类型准备纯UI/解析与原缺口复现；实际Host链接、持久化联验须等Root确认其冻源。

本轮完整目标：从正常产品入口用原PutObject明确创作DeviceInstance.item_layout、StockLocation.item_layout、ItemType.contents_layout；新修订运行后在原唯一FactoryScene显示真实物品；保存搬移/旧Run继续其精确冻结layout/模块，缺项具体可见。三个新Option、ItemSlotAssignment/ItemSlotLayout/ItemDisplaySlot取正常生成类型，不再定义一份独立持久化格式。

创作使用结构化表单：明确选择item_id_order、精确child type@revision、设备/容器的命名scene_node角色、位置/旋转/缩放及单位/坐标系；库位偏移相对原Location且anchor_role=null。未声明布局与明确空布局可区分，新增槽的所有值须在表单明示后由用户应用，不为旧对象自动填默认槽。通过原ApplyCommands/ProjectR/UndoRedo写完整owner，保留取消、冲突的本地输入；Root只需挂载新工作区并传原onApply，勿另造历史或保存通道。角色从最终精确媒体取，不从工艺RoleBindings/端口名猜；缺角色/媒体保具体缺项，展示槽不改变业务capacity。

正式场景从同一次read的FrozenProject+完整ItemsAt/JobsAt纯解析，不再要求没有生产者的readItemAttachments Host/Native端点。每个实际holder+type@R为一池（多个同设备Job不得各复制物理槽），剔除transformed/scrapped，按明确的确定ID字典序配到该类型声明slots顺序；不解析ID数字后缀、不按数量复制batch身份。超槽整组明确N身份/M槽并不绘制该组，ID/历史全部仍可查。job取同JobsAt执行设备、location取真实hall/position、container取双向holder/contents及合法父链；composition不是contents。transport当前无真实Pose，明确不支持，不猜路径或建立另一个时钟。

持久化的是逻辑anchor_role与Pose；在原resolver/LOD/精确媒体/rig完成后解析最终Presentation的scene_node canonical索引。不能把详细LOD的AssetRef/index硬套简化；合法native_scene的asset=null不要求伪造GLB AssetRef。继续原meters/Y-Z-up父层级、实际机构姿态与资源所有权，offset只叠加一次，不fit/normalize。父容器缺合法空间或模型时子物品不落原点。展示是明确的时点代表布局，不冒称永久占位/碰撞/运输求解。

独占生产写范围：`services/factoryPresentation.ts`、`scene/factoryItems.ts`、必要的`scene/factoryMedia.ts`、新`features/item-layout/`；新`tests/planner/item-layout/`与`scenarios/媒体表现/runtime-item-layout-consumer/`。Root独占Workbench挂载、Host/domain/API/生成器/Native/原设计与任务JSON；FactoryScene只有确切必要接点先向Root具名申请。原媒体resolver/解码/时钟不得复制。原显式探针接口若随正式纯投影删除，保留原文件副本/原始证据，具名报告仅内部接线资格演进与对应的等价空间/迟到/错误守门期待；不得改旧业务数字或把原两项非持久化探针升级为持久化通过。

必要真实验证涵盖正常结构化创作→原同Host PutObject→Run设备/库位/真实容器三种位置，实际等待/移交/反向seek、两个LOD/合法native_scene/非单位尺度/双厂房与线坐标、缺槽/错版本/缺角色/父链/transport明确缺项，实际RunR1与当前R2改layout或显式v2采用后仍冻结旧源，真实Save/物理搬移freshHost再读取。比较原全部事件/数量/时间/资源及旧九Run不变，晚模型/切Scope/R/卸载不覆盖新场景。Root入口挂载后再共同TS/build；完整自审一次冻源交Root。

工业八设备同等级取[共同规范](../../02_交互设计/设备建模精度与表现验收规范.md)，不缩小、换方块或隐藏身份达NFR。本轮不追加节点编辑Host能力/P302-NODE-OWNER-01或RenderView，原immutable-texture警告只有实际重现并修根因后才可关闭；Native/工业/NFR/IX/人类release仍走原硬门。
