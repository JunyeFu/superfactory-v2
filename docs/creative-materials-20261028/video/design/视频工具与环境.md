## 可直接复用的命令

在产品根目录执行。以下命令不会变更产品代码，实际录制只能在共享Native资源交回后进行。

```powershell
# 重建隔离Remotion依赖时，先复制工具锁文件；不要在产品目录安装。
Copy-Item tools/video-production/remotion-tools/package*.json F:/SuperFactory-v2-video-20261028/tools/
npm ci --prefix F:/SuperFactory-v2-video-20261028/tools --ignore-scripts --no-audit --no-fund

# 合成工具测试：新目录，不捕获桌面，不播放扬声器。
python -B tools/video-production/smoke-video.py --output-dir F:/SuperFactory-v2-video-20261028/smoke-next

# 从UTF-8旁白生成WAV；输出必须是新文件。使用当前可用pwsh，不修改安全策略。
pwsh -NoProfile -File tools/video-production/synthesize-narration.ps1 -TextFile F:/SuperFactory-v2-video-20261028/narration.txt -OutputWav F:/SuperFactory-v2-video-20261028/narration.wav

# 读取候选身份/客户区/主副屏，默认只列计划、不移动或录制窗口。
pwsh -NoProfile -File tools/video-production/capture-native.ps1 -TargetProcessId <实际PID> -ExpectedExecutable <最终候选绝对exe路径>

# 资源交回、确认演示工程已保存后，显式启用录制。只移动指定候选到当前副屏。
pwsh -NoProfile -File tools/video-production/capture-native.ps1 -TargetProcessId <实际PID> -ExpectedExecutable <最终候选绝对exe路径> -Seconds 20 -OutputFile F:/SuperFactory-v2-video-20261028/shot-01.mp4 -Capture
```

原`capture-native.ps1`仅完成语法检查；本批真实录制使用`record-demo.mjs`及已核对的精确PID/Tauri Window客户区定位，FFmpeg副屏区域录制、连续设备回放、正常保存与新进程读回均已执行。首批实际路径及失败修复见录制状态，不把尚未实测的旧helper写成通过。屏幕区域录制会包含该区域的遮挡窗口；拍摄须只安排本任务候选，不能操作或录入用户工作窗口。双屏选择按当前Primary标记；不修改主屏，不硬编码DISPLAY编号。

真正制作时每个镜头保留原片，剪辑工程只引用真实路径；同候选产品画面配离线旁白/SRT，默认不加BGM。最终视频全片播放核对一次即可，不增加压力或严格帧计量矩阵。
