# 超级工厂介绍材料：制作与表达规范

更新：2026-10-28。适用范围：作品介绍的构思、写作、配图、排版、演示编排与交付。依据：[全方面学习与原件拆解](参考资料/20261028_展示文档学习/全方面拆解_思路制作内容表达.md)。本文件不改变产品需求或接管实现、录制与发布。

## 1. 先写读者结论，再制作页面

已安装的工作链为 `product-marketing → sales-enablement → scientific-slides → 应用内pdf`。先读取软件工程目录的 `.agents/product-marketing.md`，再消费本稿、编制方案与实际材料；环境入口见[制作环境](文档制作环境/README.md)。外部技能提出的客户故事、ROI或收费信息，仅在本项目取得相应资料时采用，不照抄示例数字。scientific-slides的口头幻灯片密度建议用于路演；独立阅读PDF仍按本规范解释完整。

每页的编制说明包括四件事：读者看完应理解的结论；支撑它的事实或实际操作；采用的画面形态；下一页为何接在这里。没有明确用途的装饰、参数和截图不占主体空间。

读者沿“目标与条件—建立工程—观察约束—修改比较—交付接手”理解产品。九类概念、Agent、纸包装和软件在环分别解释其中的能力。作品整体仍为可编辑的通用工业模拟与生产评估平台。

产业背景统一取[任务8关联说明](产业背景与任务8关联说明.md)。开场给出省重点领域研发计划母项目、任务8与本作品的关系，再说明实际用户工作；背景名称不是装饰，也不能用母项目指标代替本作品成果。

14章已展开为18页阅读审阅版；18页是当前编排结果，内容讲不清时可以扩页或加入附录。用户需要的说明不因页数被删去，也不靠缩小字号硬塞。

## 2. 标题、正文、图注各有工作

- **标题**尽量说明本页结论或用户能完成的动作，避免只写“系统架构”“核心优势”等抽象名词。
- **正文**解释动作、规则和后果，先具体例子再专业概念。一个段落推进一个意思，不把十几个功能名排成一句。
- **图注**指出选中对象、操作、时刻及可见变化；不重复标题，也不让读者在图里猜箭头。
- **证据说明**贴近对应结果，包含必要的版本、输入、单位和范围。详细原始路径放附录，不占主叙事。
- **口头说明**先告诉观众要观察什么，再操作、停顿、解释结果。不要一边快速换页一边逐字念满屏正文。

写作采用“谁遇到什么问题—怎样操作—系统依据什么处理—结果支持什么决定”。未经支持的领先、最优、降本增效和市场份额不写成结论。

## 3. 页面类型与视觉语言

用户已确认采用专业产品介绍册，允许适度色块、线条和图形装饰，真实软件画面为主。具体外观及三页母版见[外观设计规范](外观设计规范.md)，不再按纯文字企业技术文书的视觉密度组织。

现有工业桌面风格不变。制作时以这些页面类型组合，不必每页强行套同一布局：

|类型|主体|适合内容|需要避免|
|---|---|---|---|
|开场页|真实工作台主图＋一句价值＋使用对象|作品识别、任务目标|无来源工厂照片压过软件；一屏堆全部模块|
|任务页|用户输入与需要作出的决定|背景、使用场景、采用理由|宏观口号与大市场数字取代具体任务|
|连续过程页|少量连续画面＋短动作说明|搭建、等待、专业接续、Agent操作|跨工程拼成同一次运行；裁掉关键条件|
|机制页|一张可读结构图＋实例局部|定义与消费者、运行责任、接点|只列组件名；源码路径代替解释|
|比较页|同视角前后画面＋同口径结果|方案比较、操作后果|无分母百分比；全部变化都涂绿|
|接手页|真实资产与操作入口|开源复用、贡献、采用|只有仓库Logo、二维码和承诺清单|

标题、正文、图注、边距和页码保持稳定。全景、局部和结果图允许不同占比，读者视线先看到本页结论，再看到支撑它的主体。

当前阅读版横向A4的起始设置：标题24—30pt、正文约10.5—11.1pt、图注9—10pt、页边距约12—15mm。它们是编辑起点，不是赛事限制；最终以实际中文排版及正常尺寸可读为准。不得照搬参考宣传册9pt正文作为我们的密集主文。

状态颜色沿用实际软件含义，标注色仅引导关注，不另造一套业务状态。避免无业务意义的发光、渐变、占位仪表和装饰卡片。

## 4. 各类素材怎样制作

|素材|制作办法|读者必须能理解的事|
|---|---|---|
|真实截图|保留原始画面；另做裁切与标注层；同案例统一视角|这是哪个对象、做了哪项操作、改变了什么|
|设备近景|使用实际模型与动作，突出本页涉及的机构和物品关系|设备如何处理物品；可视表现与业务状态怎样对应|
|连续图|选择初态、关键过程和结果，固定关键对象，保留时刻|输入到响应的因果及先后|
|结果图表|使用实际输出，保留单位、窗口及对照条件|数字回答哪个决定，有哪些适用条件|
|机制示意|自有可编辑图形；用业务对象和消费关系解释|定义由谁编辑、由谁使用、状态归谁维护|
|AI生成图|仅用于明确标识的背景、概念或设计说明|它不是实际软件界面、实测数据或现场能力证明|
|第三方参考图|留在研究对照；正式引用按来源与许可处理|它是谁的案例，为什么出现，不是本项目成果|

不能改写截图中的业务数值、伪造连续状态、用AI界面补缺失能力。不同Run和不同工程明确区分。图像清晰度不仅看像素数量，还看排到最终页面后字段是否可读；放大模糊原图不会增加细节。

表格和图表尽量保留矢量与可编辑文字，不将整页压成一张图片。复杂全景可以裁局部配定位，不能把所有设备、面板和图表缩到一页里。

## 5. 动态演示与旁白

首个完整片段尽早给出真实操作和可见变化；之后再展开模块机制。讲解每个动作遵循：说明目的，操作，给观众看响应，再解释它对任务的意义。

镜头以工厂画布为稳定参照；确需读参数时再切局部。一次重点只引导观众关注少量对象，鼠标动作有目的；不频繁无理由旋转、飞行或跳页。

时间轴区分仿真时刻与播放速度。跳过等待要说明跳转；历史回看、重算和当前执行分别标识。字幕简短指出动作和结果，不把整段说明文字重复覆盖在画面上。

旁白需要实际试听检查清楚程度和节奏。背景音乐如使用，不压住讲解；无声观看也应能靠字幕理解核心过程。技术问答从实际例子和机制解释，记不清的值回到来源，不临场补数字。

任务8是产业需求来源和执行侧接续环节；软件在环素材是其中的一个具体实例。实例切换明确转场与版本，停止新接单、已经开始的工作及后续接续分别展示。它与工厂模拟属于同一产品工作链，两个设备的具体实例也不能代替完整平台的展示。

## 6. 制作顺序与可编辑源

1. **定结论与读者路径。** 沿14章内容及18页现有页面清单写每页要表达的事实、主图和承接关系。
2. **对齐文案与镜头。** 先写可读文字和具体画面要求，标出已有素材及真实缺口；不先填装饰图。
3. **做少量代表页面。** 开场、连续过程、比较或机制页先验证字体、图像和阅读顺序，再复用到全篇。
4. **制作素材。** 消费已有实际候选画面与结果；裁切、图表和标注分层编辑；缺失运行画面列入后续素材任务。
5. **完整排版。** 复用现有PDF生成链或可编辑页面工具；复杂页面需要频繁手调时可采用PowerPoint兼容源。工具不是完成标准，不因参考作者使用某软件就照搬。
6. **导出并看成品。** 检查整组缩略图的节奏，再逐页按实际尺寸看字、表、图和留白；核对链接与三项材料的版本归属。修改源文件后重新导出，避免只修PDF而源稿失配。
7. **交付。** 保留正文、排版源、实际使用素材与来源、PDF和对应视频入口。正式包不混入参考厂商原件、缓存或未采用草稿。

本窗口可完成文字、页面设计、图注、排版和审校；运行素材沿已有主责提供的实际产物消费，不为制作介绍重启产品全量验收。

## 7. 完成时实际看哪些方面

检查思路是否聚焦、叙事是否连贯、内容是否完整、表达是否可懂、图像是否真实、排版是否可读、演示是否看得见处理、结果是否口径一致、制作源是否可修改、交付是否能接手。以上分别针对实际材料，不以编制规范存在或程序导出成功代替成品质量。
