# 介绍文档外观：专业产品介绍册

2026-10-28，用户已确认体裁：**专业产品介绍册；适度色块、线条与图形装饰，真实软件画面为主，兼顾吸引力与可信度。**

## 外观方向

采用克制的工业编辑设计。大标题让读者先认出产品与用途，真实工作台建立直观认识，局部过程和实际结果解释能力。产业背景以清楚的文字与来源区域呈现。

外观母版v01包含封面、连续过程、结果比较三类页面，见[三页PDF](外观母版_v01/超级工厂_产品介绍册_外观母版_v01.pdf)。体裁已经确认；以下配色、具体版式与字号属于本轮设计建议，可按实际画面反馈调整。

## 装饰怎样使用

- 标题前的短色条和章节编号，建立阅读位置。
- 细分隔线、图注底条与小范围色块，区分结论、画面及来源。
- 局部浅网格，呼应工厂画布的空间感，只在空白区使用。
- 结果和过程状态沿真实含义强调；配色不替代文字与单位。

装饰围绕内容工作，正文和真实画面拥有优先空间。页面上的设备来自本项目实际软件素材；软件中的字段和业务状态保留原貌。

## 配色与文字层级

字体采用当前环境可稳定生成中文PDF的微软雅黑常规与粗体。内页用稳定的字号和对齐建立秩序，封面允许更大的标题层级。

## 三类页面的具体安排

**封面：**左侧产品名、价值主句、简短用途与产业背景；右侧真实软件主图及简短图注。用文字说明项目来源和美的牵头需求，保持产品主体清楚。

**连续过程：**同一已保存运行的两个时刻并排。画面下方用可读文字概括进度、资源与物品状态，再用实际时间轴连接解释。图外摘要与软件截图的边界清楚。

**结果比较：**用相同单位的原始数据画简单比较图；旁边解释改变了什么，下面交代共同输入、实际变化和结果归属。保留来源，不将执行变化称作收益改善。

## 本轮素材和完成范围

母版使用已发布v2.0.0介绍源包中的设备过程及时间轴截图、任务8技术答复中的既有软件在环结果。两份实例分别保持归属；本轮没有重跑产品，也没有把这些画面标为最新候选的整厂验证。
