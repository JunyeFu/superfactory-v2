## 重新生成

使用已配置的Codex文档Python（ReportLab、Pillow、pypdf、pdfplumber），以及Windows微软雅黑字体。字体文件不在本源包内重新分发。

```powershell
$docPython='C:\Users\fujunye\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $docPython .\build_brochure.py
```

只有机制图变化时，先修改`create_diagrams.py`或原生`.drawio`并导出对应PNG。脚本使用本机draw.io：

```powershell
& $docPython .\create_diagrams.py
& $docPython .\build_brochure.py
```

在其他机器上使用时，将脚本中draw.io及字体路径改为实际安装位置。文案和排版需要分别编辑：章节原文在Markdown中；为成册而改写的文字、阅读导览、图注与参考页在生成脚本中。脚本按整段中文高度检测溢出；实际图像和阅读节奏仍须看渲染页。
