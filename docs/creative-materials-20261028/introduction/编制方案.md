# 作品介绍编制方案

更新：2026-10-28。用户授权本窗口负责介绍文档的设计、写作、安排。本文件只管理 MAT-02，不接管产品实现、实录录制、发布或正式提交。

## 文档要完成的事

面向第一次接触项目的评委，让其能依次回答：谁在什么情况下使用；输入什么、怎样操作、得到什么；系统为什么能解释结果；已有通用能力与本项目贡献如何区分；实际做到了哪里；开源后别人如何使用、修改和贡献。

主线固定为“可编辑的通用工业模拟与生产评估平台”。纸包装是首个深入展示领域；真实云端软件在环执行是模型与执行衔接的实例。两者共同说明平台的可扩展与一致性，不将作品缩写为单一纸箱工具或两设备派工看板。九类业务概念、模块自定义、两画布、Agent共同业务入口、运行评估和可编辑交付是贯通主线。

产业背景按[产业背景与任务8关联说明](产业背景与任务8关联说明.md)统一：超级工厂是广东省重点领域研发计划项目《面向典型行业的工业软件集成及全价值链工业互联网平台搭建》（2019B010120001）任务8的延伸课题，结合美的牵头需求下的任务8原型与工厂流水线模拟。母项目亦属广东省科技计划项目。本册第2—4页说明来源和用户任务，后续展示模型、数据、作业与评估怎样接续。

官网要求为项目背景、技术架构、应用场景及创新点；文中同时覆盖技术创新30%、场景落地30%、开源治理20%、长期发展20%。权重用于分配论证篇幅，不编造项目得分。来源：https://www.oschina.net/oa2026/ 。

本轮已对照工业仿真宣传册、连续教程、客户案例、开源会议讲稿与比赛资料，学习记录见[同类展示材料学习与改版结论](参考资料/20261028_展示文档学习/同类展示材料学习与改版结论.md)。采用“用户要做的决定—可编辑方案—运行与变化—可信结果—接手复用”的组织方式；学习不改变产品功能范围。

按用户补充，学习范围覆盖构思、叙事、内容、文案、视觉、图像与图表、动态演示、证据、制作工艺、传播与交付。39页整组视觉对照及实际演示抽帧见[全方面拆解](参考资料/20261028_展示文档学习/全方面拆解_思路制作内容表达.md)；实际制作统一按[制作与表达规范](制作与表达规范.md)，不再只以内容目录约束材料质量。

作品介绍面向全平台理解；已交付的任务8五页答复面向要求与技术证据；视频面向连续操作和画面因果。三者互相引用，不把任务8答复直接扩写为全平台介绍，也不把动画播放器当成可重算的工程交付。

## 版式与配图规范

- 体裁已由用户确认为“专业产品介绍册”，允许适量装饰；外观规范与三页代表母版见[外观设计规范](外观设计规范.md)。正文页以过程和真实结果为主，产业背景区域保持规范来源表达。
- 工业桌面风格，使用项目已有的色彩和控件语义。白／浅灰底、深色正文、少量状态强调色；不加入无业务含义的装饰面板。
- 一页一个论点。正文采用10.5—11.1pt，配合充足行距，图注9—10pt，图内文字在最终页面尺寸下可读。标题、图注、页码及边距统一。
- 优先复用真实软件截图与已确认的设计资产。涉及实际运行结果的主图必须来自对应运行；设计示意单独标注。图片可以裁切放大，但不能改写结果或拼成不存在的操作状态。
- 用连续画面体现处理：输入或初态 → 系统过程 → 变化／结果。不能仅用全景设备陈列说明“完成生产”。
- 全景负责讲空间和连接，局部负责读参数和等待。将当前论点涉及的设备、字段或曲线突出显示；不复制参考宣传册中密集的窗口拼贴。PDF缩到正常阅读尺寸仍应看清关键值。
- 主案例使用同一工程及可辨认对象；修改后的对照运行单独标识。任务8软件在环例子是另一个实例，明确转场和版本，不拼成一条不存在的完整运行。
- 一张输入／结果图至少能回答选中了谁、做了什么、系统怎样响应、用户下一步据此决定什么。图注解释因果，不重复标题。
- 每幅图在素材表注明来源、所示能力、版本、需要的图注和替换条件。截图中的工程名、数量、状态与正文一致。
- 正文避免源码路径、PID、测试名称堆积。必要证据与原始路径放编制状态或附录；读者优先看到业务因果。
- 标题给本页结论，正文解释原因，图注指出对象、操作与变化。先按开场、任务、连续过程、机制、比较、接手六种页面类型制作少量代表页，再展开全篇。
- PDF按独立阅读设计；口头演示按观察和讲解设计，不能直接朗读密集正文。截图、标注、图表和文字保留可编辑源；先检查整组阅读节奏，再逐页看最终尺寸。

## 结果、贡献和开源的写作口径

- 比较先交代相同需求、初态、观察窗口与实际改变的因素，再给现有输出的单位和解释。需求换算、仿真预测、软件在环实测、现场收益分别表述；测试数量和数据规模不直接换算商业收益。
- 已有产品覆盖3D、层级模型、资源分析、自定义组件和分享等能力。本作品按完整任务陈述自己的实现和组合贡献；没有完整对比证据时，不写成竞品无法完成或全球首创。
- 开源要展示接手路径与可复用资产，而非承诺列表。代码、工程、模块、素材、Agent说明逐项按实际可取得范围介绍；软件许可不代替模型与图片许可。
- 市场先讲具体采用者、准备条件和业务决策价值。目前未取得的用户工时、采购、收入或份额数字不补估；研究材料中的客户收益归原案例。
- PDF页数与视频剪辑服从表达需要。相邻赛事资料只学习组织方式，本届格式按现行官方要求。

本窗口负责上述全部文案、图式安排、版式、图注及审校，不自行拆出新的Agent或窗口。实现窗口继续产出其范围内的最终候选和证据；这里消费已形成的材料，不为写介绍重跑产品矩阵或干扰正在工作的窗口。
