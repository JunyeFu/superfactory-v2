# 固定设备贡献模板

复制本目录到对应modules分类的独立目录，填写manifest.json；将可再分发素材放assets/，提供example.json场景片段。此模板目前是设计提案格式，运行格式由P0/P3落实。

本模板category=devices，只适合固定设备；其他类别从[类别入口](../README.md)选择，不复制本文件的behavior/播放状态当物品或资源。

必填说明：
- 解决的任务和使用对象；
- 输入、输出、单位、前置条件及耗时依据；
- 可设置参数、可用操作、等待/完成的含义；
- 素材来源、作者、许可、修改情况（没有素材也可用内置图标）；
- 示例中应出现的现象、尚不支持的行为；
- 维护联系人或仓库账号，不要求私人联系方式。

不附完整第三方手册、无授权模型或生产数据。GIF和3D动作仅表现状态；示例数值注明假设。

自定义时间轴可使用presentation/timeline.json：排序图片／姿态片段、设置周期区间，给标签绑定预设数据或已声明操作。用归一化进度跟随同一工序耗时，不重复存一个总工时；回看与视觉循环不产生物品。参考[装配台样例](../../../modules/devices/manual-assembly/README.md)及[时间轴规格](../../../docs/02_交互设计/设备时间轴与标签设计.md)。只有一张图时不必填写时间轴；模板中的空路径是待填写项。

原生外观可使用presentation/native-scene.json，声明命名部件、姿态、端口锚点与标签。Agent生成和人工编辑共用这一包，不提交单张AI界面图冒充可编辑设备。贡献需说明哪些数值来自用户、哪些是演示假设，并为参考图、导入图片／模型和本项目生成数据分别填写许可。

多阶段过程绑定真实phase_id和阶段有效进度，资源等待时保留相应姿态；不将所有waiting统一绘为空闲。定义与工程实例分开，包不携带正式库存。升级说明列公开参数、端口和支持范围的变化；是否采用由工程使用者决定。参考[作者到使用者流程](../../../docs/02_交互设计/自定义设备创作与采用.md)。
