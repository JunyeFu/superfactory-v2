# 模板支持样例

`catalog.json`包含九类现行公共`ModulePackage`样例，均来自本项目已有明确设计适配资产。八类在本目录各自子目录保存；Templates类使用`modules/templates/carton-factory/candidate`的实际候选，不伪装旧设计JSON为运行工程。

这些是可创作、可进入共同导入/采用流程的公共类型样例。它们不是九个已通过完整P3验收的编辑器，也不是Host已注册的专业提供者。Professional只声明输入/输出和用途；Media的production_effect为none；Transport的实际时间/资源须由用户声明。具体执行能力仍由既有消费者决定。

素材作者、许可和再分发未确认的字段保留原值；本地类型或运行测试不构成许可授予。实际任务/源/消费者见P4-01执行JSON及`scenarios/模板与交接/runtime/README.md`。不设任意“12种对象”门槛。
