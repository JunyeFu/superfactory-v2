## 设备建模共同基准

详细设备统一按[八设备同等级建模规范](../../../docs/02_交互设计/设备建模精度与表现验收规范.md)：完整背底、关键机构与装配连接、同等级材质细部、命名活动部件及实际阶段动作。设备详情和流水线详细档一致；简化/区域LOD、插图接入或方块教学样例不降低详细档要求。面数/节点数不是独立通过条件，资产认可和产品实测仍据真实结果。
<!-- equipment-model-quality:end -->

该目录是可检查的声明设计，尚非可运行插件或真实设备模型。原有行为保持：壳体1件＋PCB1片，占用装配人员1名，经过60秒示意工时形成装配体1件。原生执行头动作仅表现这道工序，不能解释为真实压装工艺或新增自动化产能。

文件：manifest.json定义设备、端口、参数和行为；presentation/native-scene.json定义台面、底座、立柱、执行头、治具及端口锚点；presentation/timeline.json定义四个过程片段与数据／操作标签。尺寸、工时和阶段均为自建演示假设，未声明可制造精度。

|阶段|进度|60秒示例对应时间|画面|
|---|---|---|---|
|定位|0—0.2|0—12秒|治具与回位执行头，显示PCB可用量|
|下压|0.2—0.55|12—33秒|执行头由open姿态移动到pressed，进度标签随部件|
|保持|0.55—0.85|33—51秒|保持下压姿态，读数来自周期状态|
|回位|0.85—1|51—60秒|执行头回位；完成产出由行为决定|

用户可把四个原生姿态片段换成自己上传并声明许可的图片序列，保留片段ID、阶段和时间区间，再调整各图锚点。图片只引用包内导入资产；未附素材时不会假装存在照片。单周期工时参数绑定behavior.duration.value，只有一个工时值；例如改为30秒，四段自动变为0—6、6—16.5、16.5—25.5、25.5—30秒。

预设标签示例：PCB可用量、周期进度、等待原因、工时设置热点、工序查看热点、隔离试运行热点。只读标签不能直接改库存，操作名称必须出现在manifest.operations。时间轴回看和循环观看不会增加正式产量。

本例waiting/open只声明未开工的等待姿态，不适用于阶段中断或输出待接收。新增多阶段设备由实际阶段进度和持有状态选择画面，不能照搬open。模块定义不带正式库存，采用时把端口和资源角色绑定到工程对象；旧实例不因库中草稿修改自动升级。完整规则见[设备创作与采用](../../../docs/02_交互设计/自定义设备创作与采用.md)。

待验收场景沿用[人工装配样例](../../../scenarios/人工装配样例.json)：壳体2件、PCB1片、工人1名，只能完成1件；持续生产随后等待PCB。样例存量与工时不是行业数据。

贡献者可独立修改部件外观、过程片段、标签或工序参数，并提供同一场景下的解释。当前作者／许可未声明，发布前填写真实信息；没有第三方设备照片或商业模型随包分发。
