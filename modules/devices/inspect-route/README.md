# 检验与分流模块设计

检验耗时10秒并占用inspector角色人员。读取场景明确提供的结果：pass→合格端口，fail且未达返工上限→返工端口，达到上限仍fail→隔离端口，unknown/缺失→工位待判。物品ID保持，任何一次只能进入一个去向。

上限1表示最多完成一次返工，不是只允许检验一次。接收队列满时保留结果并等待，不重复创建物品。预设结果按当前物品的原始壳体祖先及检验次数匹配；此来源仅用于演示，不代表视觉模型。参数、人员和结果均为样例声明。

示例见[并行工程](../../../scenarios/并行汇合与返工/README.md)。当前未实现运行模块，作者和许可待填写。
