# 固定工时转换模块设计

输入1件指定物品，经过声明工时输出1件指定物品；输出保留输入的来源关系。模块默认示意配置为raw_shell→shell、30秒。设备实例可通过input_item、output_item、cycle_seconds参数配置为raw_pcb→pcb、20秒。参数覆盖先写入声明绑定字段，再解析端口的item_parameter；图标不决定物品类型。

这是名义加工/准备工序，单设备并发1，未包含机加工物理或真实PCB生产。默认无附加人员资源，所需实际人工应在具体模块中声明。示例见[并行工程](../../../scenarios/并行汇合与返工/README.md)，当前未实现运行模块，作者和许可待填写。
