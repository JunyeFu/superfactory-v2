# 专业桌面声明输入

四份 `.job.json` 原样复制自现行 `paper-packaging/templates/` 的 canonical Versioned PackageStructureJob 声明：三机制明确候选及空白入口。声明材料和容差/预算的原来源文字保留；不是新计算回执、现场认可或库存。界面选择后必须显式保存实际 Scope 的 Job，再调用真实 compute_packaging。

此目录不是注册的 ModulePackage，不改变现有专业提供者，也不把设计文档改名为运行成果。生成/同步入口为 `tests/planner/packaging/generate-inputs.py`；旧声明与核心独立预期只读。
