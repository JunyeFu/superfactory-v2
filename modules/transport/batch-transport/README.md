# 单批次跨厂搬运与返程设计样例

manifest.json声明transport行为：每批1件装配体，保持货物ID；占用搬运资源进行装载、去程、卸载和返程。本例四段分别为10/30/10/30秒，均为示意假设，非道路或物流实测。当前没有运行模块。

装载先预留来源物品，发出时才转为在途；接收条件满足并卸载后，货物进入目的库位供下游使用。搬运资源需要返程完成才接下一单。接收受阻时保持货物与资源，不能把未接收物品算作下游可用量。

本模块属于物流规则，不因有默认图标就变成固定设备。配合场景中的人员、AGV或其他已声明资源使用；本样例具体分配一名搬运人员，图标/连线仅表达状态。运输周期时长由四段求和显示，不再保存一个独立总工时。

输入/输出端口描述同一批货物的移动，不采用装配的“消耗输入、创建新物品”规则。样例工程见[两厂房装配包装](../../../scenarios/两厂房装配包装/README.md)。发布前填写作者和许可。
