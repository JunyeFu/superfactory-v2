## 文件与接手

- `installable/<设备>[-simple]/`：新增媒体模块、GLB、铭牌、许可、源与自身重建参数；`b01-*`为5种旧设备的1.0.1修订包。
- `devices/<设备>/module.json`：设备定义，只依赖自己的两个媒体版本。索引根目录不是批量ModulePackage。
- `batches/`：每批实际50种的清单、双档导出记录；`B01-revisions.json`记录5种旧设备的修订。
- `register-directories.txt`：以本目录为根的登记目录，先简化媒体、详细媒体、设备。包含保留旧目录的相对引用，不复制45种旧设备为新类型。
- `source/`：批次清单、具名机械组件和导出工具。全部新增造型、铭牌及2K微表面为原创CC0；未使用厂商CAD或照片贴壳。

节点、父子关系、米制/Y-up、原点、布局、端口、工位和load/auto/unload动作写入GLB和Presentation。保留旧设备沿用自己的实际阶段。`production_effect=none`：动画只读取阶段进度，不维护库存、工件副本或第二套生产时钟。

新增定义的输入输出是代表件/代表批，数量和周期为声明示例。用于真实工程时，需要绑定具体物品定义、批量、耗材、资源、质量输入和布局；连续料液/纸幅的工业衡算、切削工艺、热过程等专业模型不由媒体动作替代。当前并未完成500种设备的全部“9类概念”工业定义或500种真实生产流程验收。

## 重建与审阅

依赖项目现有Node、Three.js 0.186.1；制作铭牌需带Pillow的Python。没有新增依赖安装或收费生成调用。

```powershell
$env:SF_NATIVE500_PYTHON='<带Pillow的Python绝对路径>'
node modules/media/native-equipment-500/source/generate-batch.mjs B02
node modules/media/native-equipment-500/source/index-batches.mjs
node tools/3d-proof/native500/server.mjs
```

审阅器地址为`http://127.0.0.1:19291/tools/3d-proof/native500/index.html`；支持自由旋转、双档、七向、阶段拖动和逐批检查。原样修改/重导出后应重查受影响源、画面和MQ记录，不能沿用旧图补签。

单个新增媒体包在可解析项目Three.js依赖的目录执行`node source/export.mjs`即可重建；5种B01修订包执行`node source/generate.mjs`。每包带自身参数，不需要读取500种总清单。Host公共启动接入由协调窗口按本索引接入并核对现有登记重叠；本轮Host证明来自当前Rust消费者的独立登记/查询，不表示桌面应用启动菜单已增加500项。
