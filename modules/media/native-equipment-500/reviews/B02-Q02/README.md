# B02-Q02 · 分张与卷材纸包装复审

本批5种已完成MQ与真实Native复审，计入后正式支持总数为10/500。具体输入、输出和独立预期见review-scope.json。

物品的`presentation_state`必须在ItemType.attribute_schema声明为enum，由真实物品属性选择同名媒体阶段。若物品媒体声明`rolled:auto`这样的“状态:阶段”，仅当物品确实由该Job持有且实际快照唯一匹配时，使用同一ActualMediaFrame的阶段/有效进度；物品在Location中只显示有限状态，不产生生产进度。既有纸箱`closure`仍按原规则显示。

设备模型不内嵌纸卷、纸幅或成品纸张。卷层/穿纸路径/加工中的待成品可作为同一个真实持有纸材批的媒体子部件，不能生成额外库存；加工边界后由引擎更新形态或创建2个窄纸卷、60个纸张Item。卷材的长度/幅宽/厚度和输出面积检查来自冻结业务输入，不能从动画推算业务量。

单位piece在卷材工序表示一个明确长度的纸材批，在横切输出表示一张纸；两个ItemType分别声明，不把30米、1卷和60张混成同一个数量。芯轴是可复用设备工装，纸材是独立RuntimeItem。纸幅的离散卷层展示不替代连续张力或材料力学模型。

本批已逐机检查详细/简化七向视图、机构近景、接触与真实Native状态。源、Host和Native分别留证；失败试次不替代最终版通过记录。
