# B01-Q16：纸箱开箱、胶线涂布与侧缝压合

三种独立设备定义，版本均为`1.1.0`。按`simulation-efficient-v1`复审；采用L03工业机架、材料和关键机构表现等级，几何允许可视近似。正式计数以accepted登记及普通Native首启回执为准。

|设备ID|明确输入 → 输出|身份与工艺边界|
|---|---|---|
|carton-erector|1件预粘RSC平折箱坯 + 1段预切封底胶带 → 1件撑正、折底并封底的开口箱|生成新身份，保留箱坯/胶带两个来源；本实现用预切480mm胶带上料，不声称具备胶带整卷换卷/切断仿真|
|adhesive-dispenser|1件箱坯 + 1份0.300mL已可施用热熔胶 → 1件侧缝胶线箱坯|生成新身份，保留两来源；计量头保持加热，输入已可施用胶，不模拟冷颗粒熔化及热传导|
|compression-stack|1件侧缝待压合的平折纸箱 → 同一件已压合纸箱|原ID、数量和质量保持，`bond_state: fresh → pressed`；单件侧缝压合，不称多箱自动堆垛|

三种设备具有不同物料规格与规则，本批未将其直接串接成无需折箱工序的流水线。机械原理参照[厂家RSC开箱/折底路径](https://tekpakautomation.com/product/te-rsc-food-series-case-erector-tape-or-glue/)及[Nordson包装施胶说明](https://www.nordson.com/en/divisions/adhesive-dispensing-systems/industry/packaging)；尺寸、几何、表面和节拍为本项目原创示例，不是厂商CAD或额定性能。

## 机构、空间和精度取舍

- 共用带调平脚的型材机架、横撑/端台、输出滚筒、柜门/HMI/急停、塔灯、护窗和主要服务束。可见安装和主要动作保留，封闭总成内部不逐线建模。
- 开箱机的两套真空头分置不同高度导轨，先撑箱、折小底翼、折大底翼，再封底。端部抹带轮在撑箱和移交阶段降至工件下方，封底时升起，避免阻挡侧壁撑开路径。
- 施胶机采用XYZ胶头、定位台与八段随动热胶软管；320×3×0.3125mm胶线对应0.300mL声明用量。压合机四柱导向、中心闭式缸和压力垫具备真实行程。
- 纸板用具名刚性板和铰链表现，省略制造级折痕圆弧及纸纤维求解。约33个基础动作采样加阶段边界；不用微米、ppm或固定截图数量判合格。
- 私有成品暂存`x=0.76m`，公共输出缓冲`x=1.32m`；实际GLB检查箱体/占位物净空约328mm、涂胶坯约270mm、平折箱约290mm。两者均在输出支承范围内。
