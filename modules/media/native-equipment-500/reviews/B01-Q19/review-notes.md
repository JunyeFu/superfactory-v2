# B01-Q19：捆扎、收缩包装与六件装箱

三种独立设备定义，版本`1.1.0`，按`simulation-efficient-v1`制作与接收。双LOD、多个实例及QA清空夹具不重复计数，正式数量取accepted登记与普通Native首启回执。

|设备|本版本输入→输出|实现与边界|
|---|---|---|
|strapper|1件包件+1组两根各980mm预切PP带→同一双道捆扎包件|双门架导带、下部送带驱动及夹紧/热合头；不声称整卷自动裁断、柔性带连续力学或封口强度验证。|
|shrink-wrapper|1件包件+1件预制PE膜罩→同一收缩包装包件|升降热风罩、风机/加热服务箱及透明膜边；不模拟热传导、温度控制器或校准收缩率。|
|case-packer|6件独立产品+1只已成型开口箱→1件新包件|龙门六吸头阵列取放；空箱为包装材料来源，6个原产品成为contents；本机不折箱、不封盖。|

包件为320×240×240mm，六个产品各80×60×120mm。捆扎和收缩包装保持原包件ID、数量、质量和六个真实内装物；辅助料在auto后实际消耗，再由band_state/shrink_state及presentation_state显示。PP带供应组长1.96m；预制PE罩供应规格0.48m²、40μm，折叠搭边和厚度变化使用可视近似，几何不反算库存。示例节拍14/25/24秒，非厂家额定数据。

装箱每循环只输出1件新包件，空箱为唯一composition来源且生命周期变为transformed，6件原产品保持各自ID/1piece/released，holder转入新包件；不会把6件产品合并成一个伪物品或复制箱内模型。
