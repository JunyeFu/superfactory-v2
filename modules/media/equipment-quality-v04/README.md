## 可编辑内容与工具

使用现有Three.js **0.186.0**参数化网格/刚性层级制作，Node.js **24.15.0**导出GLB 2.0；未调用付费建模服务，也未假称连接Blender。型材截面、机架、关节、夹具、布线、倒角、空心卷材及材质均来自本项目可编辑源。`create_surfaces.py`生成本次原创2K表面，使用Pillow/NumPy；对应PNG已随源提供，不需要为重建再次生成贴图。

GLB内嵌PNG，采用核心metallic/roughness材质及当前产品支持的texture_transform；不含皮肤、变形、外链资源或专有压缩。单位为米、右手Y-up，根原点落地。尺寸来自声明式示例设计，不是厂家实测CAD。

`generate.mjs`为主源，`refine.mjs`为本轮几何返修，`surface-pack.mjs`嵌入表面，`parameters.json`声明版本与系列。每个`installable/<类别>/source/`还带有独立重建所需的相同源、参数、贴图；修改后可重新导出该包。节点、父子关系、动画索引及端口锚点从实际GLB写入对应`module.json`，没有另造运行接口。

在现有项目依赖环境从软件工程根执行：

```powershell
node modules/media/equipment-quality-v04/generate.mjs
node tools/model-quality-review/server.mjs
```

审阅器地址：`http://127.0.0.1:19289/tools/model-quality-review/index.html`。鼠标拖动环绕，选择类别/视角，播放声明动作；本机端口已登记。此工具读取当前产品共享GLB解码与场景绑定代码；历史监督参照因旧材质扩展另用Three.js标准加载器读取原文件，只作外观比较，未放宽产品导入规则。

独立重建单包时，在该包目录执行：

```powershell
node source/generate.mjs
```

需要当前项目的Three.js依赖可解析。跨机器接手时使用根`package-lock.json`锁定的依赖，不复制`node_modules`或本机可执行程序。本轮已在隔离副本逐个重开28个详细/简化包，重新导出的GLB与交付文件逐字节相同，见[重建结果](../../../scenarios/媒体表现/model-quality-20261019/batch/source-rebuild.json)。这只证明可重建，画面结论另据实际审图。
