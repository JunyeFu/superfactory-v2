## 设备建模共同基准

详细设备统一按[八设备同等级建模规范](../../docs/02_交互设计/设备建模精度与表现验收规范.md)：完整背底、关键机构与装配连接、同等级材质细部、命名活动部件及实际阶段动作。设备详情和流水线详细档一致；简化/区域LOD、插图接入或方块教学样例不降低详细档要求。面数/节点数不是独立通过条件，资产认可和产品实测仍据真实结果。
<!-- equipment-model-quality:end -->

独立贡献插图、GIF和glTF/GLB。声明许可、来源、尺度/朝向/原点、适用设备、状态与动作映射。素材不携带生产规则；设备可替换素材而保留行为。无模型也能显式选择图标彩排；图标/图片使用条件不能代替内置详细设备的三维建模质量验收。导入、预览和采用的实际可用范围以当前Host能力与消费者为准，样例存在不表示产品整包已验收。

外部Agent制作详细设备前读取[建模支持与制作指南](../../integrations/agent/skills/superfactory-workflow/references/equipment-modeling.md)。逐文件状态见[模型质量清单](model-quality-ledger.json)；登记不授予认可。交付前执行`python tools/check_model_quality.py --release-catalog <实际模块登记清单JSON>`，未完成源/导出、逐项审图、实际平台与保存重开检查的模型保持待审；测试简模不作为官方详细设备。此检查不禁止用户显式使用图片、简模和私人草稿。

新增图片序列及原生部件表现：时间轴引用包内图片资产或命名姿态，标签绑定声明数据／操作。可单独贡献图片对齐、阶段外观或原生部件；生产行为仍由设备包声明。Agent生成的数据与人工修改使用同一格式，许可声明不因生成方式而省略。

独立样例：[可编辑台面素材](editable-bench/README.md)。锚点使用input/output等角色，由采用它的设备显式映射到实际端口/读数，缺映射保留待补。更换素材不自动改变规划足迹、工时或数量。完整协议见[九类清单](../../docs/03_架构与契约/九类模块清单与消费者.md)，当前样例许可仍待发布前声明。
