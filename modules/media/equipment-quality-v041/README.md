# 14类实际GLB审阅候选：0.4.0＋0.4.1

这是14类、详细/简化共28个包的当前审阅入口。`inventory.json`逐个指向真实文件；`registration.json`选择精确版本。10类沿用0.4.0，装配台、返工台、装箱台及检验台的两档改用0.4.1。原0.4.0资产保留，未替换任何已打开工程采用的精确版本。

## 实际返修

- 四类台式设备：把背面悬空线尾接入固定在立柱上的接线盒，补电缆接头及固定件。
- 装箱台：补折板铰轴的轴承座、承托支架、减速器、电机、随折板旋转的带标记联轴器及电源接线盒。驱动体固定在机架，联轴器属于原`PackingGate`层级；没有以整台移动冒充机构动作。
- 检验台：相机壳顶到原电缆起点有5毫米间隙，补随`OpticalHead`移动的电缆接头和锁紧环。

本次通过现有Three.js参数化网格源制作，Node导出自包含GLB；没有调用或假称使用Blender。新加几何为原创CC0，沿用包内许可，不含厂家网格。尺寸为声明式示例设计；没有新增生产能力、精度或通用碰撞求解的声明。

## 可编辑源

八个修订包分别包含完整可重建的`source/`。例如从软件工程根运行：

```powershell
node modules/media/equipment-quality-v041/installable/packing/source/generate.mjs
```

其他三个类别与简化档采用对应路径。现有根锁文件中的Three.js依赖须可解析。顶层`refine.mjs`是共同修订源，其内容已复制到每个修订包的`source/refine.mjs`；单包重建不依赖旧版资产目录。

八个源在隔离副本重开后导出与候选文件逐字节一致，记录见[源重建结果](../../../scenarios/媒体表现/model-quality-20261019/batch/source-rebuild-v041.json)。这仅是源与导出对应检查，画面判断来自实际多视角及动作复核。

## 接收边界

原八设备流水线是画面基准，不使用面数或文件大小替代质量判断。详细档与简化档分别看图；简化档不代替详细档验收。新规范中的Native实际持有、四类等待及保存重开、适用性能和真人认可仍据各自真实结果接收，本轮没有为修订资产补签这些结果。
